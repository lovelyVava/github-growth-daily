## 项目分析

### 1. morluto/rea

- **主要用途**：通过统一 MCP/CLI 对网站、JavaScript/Electron 应用、.NET 程序、APK、固件和原生二进制进行证据化逆向分析。
- **技术栈**：TypeScript、Node.js 22+、MCP、Hopper/Ghidra/IDA、JADX、Binwalk/Unblob；MIT。
- **近期增长及口径**：约 **+2,963 Star/24h**，相对日增约 **46.9%**；7 天直接值缺失。当前 9,288 Star、1,024 Fork；首次进入近期前十。
- **贡献与讨论**：近 7 天提交 **≥100**、9 个作者身份、87 个新 Issue；最新增加把捕获脚本导出到 JavaScript 应用分析的能力。
- **爆发原因**：它把多个逆向工具包装为 Agent 可调用的调查流程，并强调本地运行、证据、限制与未知项，切中“让 Agent 不只猜测程序行为”的需求。
- **亮点**：既支持静态 JavaScript 分析，也能接入 Hopper/Ghidra/IDA；安装前展示变更并备份配置，结果要求附带证据和不确定性。
- **潜在风险**：逆向能力具有明显双重用途；只能分析有权研究的目标。未知样本、外部反编译器、安装脚本与 MCP 权限会扩大供应链和主机安全面。
- **适合人群与关注程度**：获授权的软件审计、兼容性研究、恶意样本隔离分析和企业 `reverse-skill` 设计团队；**★★★★★**。

- **近期增长及口径**：约 **+1,720 Star/24h**，相对日增约 **37.7%**；7 天直接值缺失。当前 6,277 Star、279 Fork，Fork 较上期 +83；连续第二。

- **爆发原因**：把 Agent 语义探索与确定性断言、路径重放结合，明显降低纯自然语言 E2E 的不确定性和重复模型成本。

## 当天技术趋势

1. **Agent 逆向从单一反编译器走向证据化编排。** `REA` 将 JavaScript、原生二进制、APK、固件和运行时行为纳入同一 MCP 工作流，并显式输出未知项；这比“让模型看反编译文本后猜测”更接近可审计研究。
2. **AI 测试正在建立确定性回路。** `e2e` 连续两天高增长且提交/作者/Fork 同步增加，说明“Agent 探索—确定性断言—路径重放”正在成为真实工程需求，而非单纯演示。
3. **Skills 的竞争点从数量转向安装、组合与治理。** `mattpocock/skills`、`Impeccable`、`agency-agents` 同时上榜；企业采用时的关键是版本、触发冲突、Hooks 权限、更新来源和可测效果。
4. **长期记忆与代码知识库逐渐汇合。** `claude-mem` 的跨宿主记忆闭环可与代码图谱、审查结果和架构事实结合，但敏感信息过滤、删除和错误召回是前置门槛。
5. **GPU 内核生态继续硬件分叉。** `DeepGEMM` 面向 NVIDIA SM90/SM100，Ascend 另开仓库；对 AMD 7900 XTX/ROCm 用户，今天的价值主要是学习内核组织与 MoE 融合思路，而不是直接部署。

## 最值得深入研究的 3 个项目

### 1. morluto/rea

REA 与企业 `reverse-skill` 的方向高度吻合：它不仅接入反编译器，还强制保留证据、限制和未知项，可借鉴为“工具调用—证据归档—结论置信度—人工批准”的控制回路。建议重点研究 JavaScript 应用图谱、Ghidra Bridge、隔离执行、目标授权清单以及如何把结果写入现有代码知识库。

### 2. tester-army/e2e

它把自然语言操作限制在可审计步骤中，并在成功后生成可重放路径，适合验证 Vue 页面、Java 微服务接口背后的跨页面流程和低代码表单。连续高增长、100+ 周提交、20 个作者和 Fork +83 说明增长质量很强。研究重点是模型步骤权限、回放失效检测、移动节点稳定性和 CI 证据输出。

### 3. thedotmack/claude-mem

claude-mem 可以补足代码知识库的“时间轴”：不仅知道静态页面—接口—字段关系，还能记录审查结论、架构决策和历史修复经验。它的跨宿主支持适合串联 Codex、Claude Code 与 Open Code Review。深入研究时应优先验证秘密信息过滤、数据驻留、记忆冲突、删除语义和召回可解释性。
