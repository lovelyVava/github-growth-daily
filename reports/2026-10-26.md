## 项目分析

### 1. cloudflare/security-audit-skill

- **主要用途**：把编码 Agent 组织成多阶段安全审计流程，覆盖侦察、覆盖率驱动挖掘、候选验证、结构化发现与独立复核。
- **技术栈**：JavaScript/Node.js、Markdown Skill、JSON Schema、coverage ledger 与零依赖校验脚本；MIT。
- **近期增长及口径**：约 **+2,264 Star/24h、+12,680 Star/7d**，相对日增约 **5.3%**。当前 45,199 Star、2,806 Fork，Fork 较上期 +148；连续第一。
- **贡献与讨论**：近 7 天默认分支 0 次提交、作者身份缺失、7 个新 Issue；最新问题指出 `validate-findings.cjs` 缺少与另一校验器对称的预解析及内存对象字段数限制，可能遭受 key amplification DoS。
- **爆发原因**：独立验证、覆盖账本和机器可校验 findings 直击 Agent 安全审计可信度；Cloudflare 品牌与 Skill 安装形态让方法论快速扩散。
- **亮点**：明确区分 confirmed、needs_validation、rejected，并要求覆盖状态、证据与复核结果形成可机器验证工件。
- **潜在风险**：无 OS 级隔离时不应执行目标代码；校验器资源上限、输出路径和历史证据绑定仍需验证。零周提交说明热度尚未同步转化为修复活动。
- **适合人群与关注程度**：AppSec、代码审查平台、Agent 安全评测和漏洞研究流程设计者；**★★★★☆**。

### 2. NVIDIA/OpenShell

- **主要用途**：为自主 Agent 提供策略约束的私有运行时，使其可访问文件、网络、软件包和凭据而不获得宿主机无限权限。
- **技术栈**：Rust、Kubernetes/容器驱动、策略引擎、网络端点控制、凭据代理与审计机制；Apache-2.0。
- **近期增长及口径**：约 **+896 Star/24h**，相对日增约 **4.8%**；快照差估算约 **+3,015 Star/7d**。当前 19,625 Star、1,940 Fork，Fork 较上期 +43；连续第二。
- **贡献与讨论**：近 7 天约 66 次提交、作者身份缺失、79 个新 Issue；最新提交为 Helm 证书 hook 增加 Pod 元数据。新问题包括 OCSF 1.8.0 顶层容器未定义，以及 gateway 重启后 sandbox 全部进入 `StartFailed`。
- **爆发原因**：Agent 权限边界正在从提示词规则转向可执行的系统隔离与网络策略；NVIDIA 品牌、Kubernetes 部署和多 Agent 运行叙事同时带来关注。
- **亮点**：把凭据、文件、网络和执行权限放进同一控制面，适合研究 Agent 沙箱、最小权限与可审计运行时。
- **潜在风险**：项目仍快速迭代，内核、seccomp、Kubernetes 和网络协议差异形成复杂兼容矩阵；策略或重启语义错误可能造成越权、误阻断或全量不可用。
- **适合人群与关注程度**：Agent 平台、云原生安全、沙箱运行时和企业凭据治理团队；**★★★★★**。
