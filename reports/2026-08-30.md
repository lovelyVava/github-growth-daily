## 统计口径与限制

1. **24 小时新增 Star**：采用 GitHub Trending 日榜的 `stars today`。这是滚动窗口指标，不等于自然日增量。
2. **7 天新增 Star**：采用周榜的 `stars this week`。本期前十仅 `archify`、`scientific-agent-skills`、`awesome-gpt-image-2`、`freellmapi` 有公开周榜值；其余标记为“缺失”，不从累计 Star 反推。
3. **Fork 变化**：仅对上一期已有快照且本期继续上榜的项目计算相邻快照差；新上榜项目不估算 24 小时 Fork。
4. **工程活跃度**：统计 2026-08-23 00:00 UTC 起约 7 天的最近提交，单仓最多读取 100 条。本次 GitHub 搜索未稳定返回作者身份，独立贡献者数标记为缺失。
5. **讨论热度**：统计同窗口内新建的 Issue 和 PR。它表示协作流量，不表示问题已解决或 PR 已合并；Discussions 无统一跨仓库增量口径，故使用 Issue/PR 作为代理。
6. **爆发原因**：根据 README、近期活动、榜单变化和公开传播线索作分析判断，不代表维护者官方结论。

## 项目分析

### 1. tt-a1i/archify

- **主要用途**：让 Agent 将代码库或系统描述转成可交互、可验证的架构图、工作流图、时序图和数据流图。
- **技术栈**：JavaScript、Node.js CLI、typed JSON IR、自包含 HTML/SVG、Agent Skill；MIT License。
- **近期增长**：日榜约 **+3,927 Star**，周榜约 **+11,099 Star**；相对日增约 **14.8%**。当前 30,460 Star、1,900 Fork；较昨日 Fork 约 **+205**。
- **贡献与讨论**：近 7 天约 31 次提交、32 个新 Issue、62 个新 PR；独立贡献者数缺失。Star、Fork 和协作活动同步增长。
- **爆发原因**：typed IR、确定性校验、源码证据和 Before/Delta/After 对比持续击中 Agent 图表“好看但不可审查”的痛点。
- **亮点**：事实层与展示层分离；生成物可校验、可修复、可导出，适合接入代码审查与文档流水线。
- **潜在风险**：模型化结果不等于真实运行拓扑；动态调用、反射与配置依赖可能漏检；内部架构分享前必须脱敏。
- **适合人群**：架构师、研发效能与代码审查团队、复杂代码库学习者。
- **值得关注程度**：**★★★★★**。连续增长且工程活动强，是“可验证 Agent 交付物”的代表。

### 6. tailscale/tailcat

- **主要用途**：像 netcat 一样在两台设备间传输数据，但使用 Tailscale 数据平面的 WireGuard 加密、NAT 穿透和 DERP 中继，不依赖控制面或账户。
- **技术栈**：Go、Tailscale `magicsock`、WireGuard、DERP、NAT traversal、WebAssembly；BSD-3-Clause License。
- **近期增长**：日榜约 **+790 Star**；周榜缺失；相对日增约 **30.8%**，前十最高。当前 3,359 Star、95 Fork；较昨日 Fork 约 **+28**。
- **贡献与讨论**：近 7 天 44 次提交、9 个新 Issue、11 个新 PR；独立贡献者数缺失，传播得到高密度工程活动支撑。
- **爆发原因**：“Tailscale without Tailscale”定位清晰，把成熟数据平面抽成无需账户和管理员权限的点对点 CLI/Go 库。
- **亮点**：端到端加密；可从中继升级为直连；不修改路由表或 DNS；连接元数据可通过任意带外渠道交换。
- **潜在风险**：元数据分发与身份认证由使用者负责；默认公共 DERP 有限流与可见元数据；浏览器模式目前主要依赖中继；短连接令牌不是长期身份体系。
- **适合人群**：网络工具、远程调试、临时安全传输、NAT 穿透及 Go 基础设施开发者。
- **值得关注程度**：**★★★★★**。相对增长、维护主体和代码活动仍同时强。

## 今日技术趋势

1. **Agent 的可信交付仍是最强主线**：`archify` 连续第一，类型化事实、校验、证据和可审查导出物形成了比单次生成更持久的价值。
2. **领域 Skills 开始从“数量库”转向证据与工具路由**：`scientific-agent-skills` 排名大幅上升，关键价值是把科学数据库访问、引用和失败边界外置成可更新能力。
3. **视觉到代码进入“生成—渲染—自检”闭环**：`screenshot-to-code` 不只产出代码，还能用浏览器预览帮助 Agent 检查结果，说明视觉编程正从一次性转换走向迭代修正。
4. **成熟安全工具重新受到 Agent 时代关注**：`ghidra` 的自动化与脚本能力可以成为二进制分析 Agent 的底层工具，但安全隔离和证据复核不可省略。
5. **安全连接原语的价值继续上升**：`tailcat` 将 WireGuard、NAT 穿透和中继抽成小型库，可服务远程工具调用、临时设备协作和隔离环境调试。
6. **讨论热度与维护能力仍明显分化**：`gods-eye-view` 的 Issue/PR 激增但提交很少；`tailcat`、`ghidra`、`freellmapi` 与 `archify` 则同时有较强代码活动。

## 最值得深入研究的 3 个项目

### 1. K-Dense-AI/scientific-agent-skills

**理由**：日增从约 720 提升到 1,604，排名从第七跃升第三，Skills 数量也继续增长。它适合研究如何用领域工具、上游引用和版本化能力降低 Agent 对模型记忆的依赖。

**建议验证**：随机抽取 10 个 Skills 检查来源、输入输出约束、失败处理和引用；数据库失效时是否安全失败；医学结论是否强制不确定性声明；Skill 版本与真实 API 是否同步。

### 2. tailscale/tailcat

**理由**：连续上榜、相对日增最高且近 7 天提交密度强。它不是 Agent 外壳，而是可嵌入远程 Agent、调试与设备协作系统的安全网络原语。

**建议验证**：连接令牌泄露后的攻击面；DERP 元数据与限流；不同 NAT、IPv6 和企业代理环境的直连成功率；断线重连、大文件校验和短期身份授权。

### 3. tt-a1i/archify

**理由**：连续三天第一，周增超过 11,000，提交、Fork 和 PR 同步上升。它将架构图变成带类型、校验、修复凭据和源码证据的工程交付物。

**建议验证**：真实多模块仓库的依赖召回率；动态调用和配置依赖漏检；生成图与 Git diff 的一致性；敏感拓扑脱敏；将架构 Delta 作为合并请求证据的集成成本。
