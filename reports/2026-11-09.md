## 项目分析

### 1. cloudflare/security-audit-skill

- **主要用途**：把编码 Agent 组织成多阶段安全审计流程，覆盖侦察、覆盖率驱动挖掘、候选验证、结构化发现和独立复核。
- **技术栈**：JavaScript/Node.js、Markdown Agent Skill、JSON Schema、coverage ledger 与零依赖校验脚本；MIT。
- **近期增长及口径**：约 **+2,085 Star/24h、≈+9,796 Star/7d**；当前 66,056 Star、4,297 Fork，Fork 较上期 +118，连续第一。
- **贡献与讨论**：近 7 天零提交、作者身份缺失、4 个新 Issue。近期问题继续指出归档验证器身份可能重新进入当前状态，以及 findings 只引用文件和行号、没有绑定原始字节的问题。
- **爆发原因（推断）**：Agent 安全审计正在从提示词清单转向覆盖账本、独立验证和机器可读 findings；Cloudflare 品牌与一键安装形态维持传播。
- **亮点**：把 confirmed、needs_validation、rejected 分离，并把覆盖状态和复核结果变成可检查工件。
- **潜在风险**：最后推送仍停在 9 月 14 日，本周零提交；未解决 Issue 直接触及证据可信度。没有 OS 级沙箱时不应让审计 Agent 执行不可信目标代码。
- **适合人群与关注程度**：AppSec、企业代码审查、Agent 安全评测和漏洞研究流程设计者；**★★★★☆**。

### 2. milind-soni/OpenMausBot

- **主要用途**：提供可自托管的多 Bot 聊天应用，让 AI Bot 在隔离虚拟机中使用浏览器、终端和文件工具完成任务。
- **技术栈**：TypeScript、Electron、Expo、Docker/虚拟机、Node.js/npm 与计算机操作 Agent；Apache-2.0。
- **近期增长及口径**：约 **+1,955 Star/24h、+7,077 Star/7d**，相对周增约 69%；当前 17,326 Star、2,440 Fork，新上榜第二。
- **贡献与讨论**：近 7 天默认分支提交、新 Issue 均达到 **100 条读取上限**；最新仍在合并问题修复。新工单包括文件被散落到宿主或 Bot 计算机、应用反复崩溃和 iOS 简化界面问题。
- **爆发原因（推断）**：把“聊天里的 Bot 团队”和可实际操作电脑的 VM 结合，演示效果强；自托管、Grok Bot 替代和多 Agent 协作共同带来传播。
- **亮点**：不是单一提示词仓库，而是包含桌面端、移动端、虚拟机和工具执行链路的可运行产品。
- **潜在风险**：工程和 Issue 同时触顶说明迭代很快但稳定性压力大；Bot 拥有终端、浏览器和文件权限，必须隔离密钥、挂载目录、网络出口和持久化数据。不要在装有生产凭据的宿主直接试运行。
- **适合人群与关注程度**：自托管 Agent、计算机操作、桌面 AI、虚拟化和多 Agent 产品团队；**★★★★☆**。

### 3. sherlock-project/sherlock

- **主要用途**：输入用户名后，在大量社交网站中查询同名账户，用于 OSINT、数字足迹调查和威胁情报侦察。
- **技术栈**：Python CLI、异步 HTTP 请求、数据驱动的网站规则、PyPI/Docker 分发；MIT。
- **近期增长及口径**：约 **+1,766 Star/24h**；7 天数据缺失，最近 2 天快照差约 +2,798。当前 101,124 Star、11,953 Fork，新上榜第三。
- **贡献与讨论**：近 7 天零提交、3 个新 Issue；问题集中在执行失败、Discord 返回基础 URL 和测试性工单。
- **爆发原因（推断）**：成熟 OSINT 工具被重新传播，用户名跨站检索具有直观演示效果；网络安全与个人数字足迹主题扩大了受众。
- **亮点**：站点覆盖广、CLI 简单、结果可导出，适合快速建立调查线索。
- **潜在风险**：同名账户不等于同一自然人，误报和站点返回结构变化都可能误导调查；使用时还涉及隐私、骚扰、站点条款和司法辖区限制。近七日零提交意味着本轮更像传播事件。
- **适合人群与关注程度**：授权 OSINT、威胁情报、品牌保护和数字取证团队；**★★★☆☆**。

### 4. NVIDIA/auto-ontology

- **主要用途**：从企业元数据构建语义本体和关系图，为 Agent 提供可信指标定义、SQL 校验、血缘与来源证据。
- **技术栈**：Python、FastAPI、Postgres、Next.js/React、MCP/CLI/API、数据库连接器与 NVIDIA NIM；Apache-2.0。
- **近期增长及口径**：Python 日榜约 **+1,155 Star/24h**；7 天值缺失，最近 4 天快照差约 +5,210。当前 9,871 Star、806 Fork，Fork +67，由第三降至第四。
- **贡献与讨论**：近 7 天约 17 次提交、28 个新 Issue；最新固定 Python 3.12.16。问题涉及 LLM 调用追踪、深色主题图表标签和查询排序被前端重排。
- **爆发原因（推断）**：企业 Agent 的瓶颈从“能否生成 SQL”转向“语义是否一致、答案能否验证”，本体、血缘和查询证据正成为新的控制面。
- **亮点**：把语义、关系、连接器、查询和答案血缘放在同一层，并提供 MCP 接口。
- **潜在风险**：错误本体或连接器结果会以“可信上下文”形式被放大；生产使用必须验证只读权限、RLS/CLS、查询成本、提示注入和审计日志。
- **适合人群与关注程度**：企业数据平台、语义层、Text-to-SQL、RAG 与 Agent 治理团队；**★★★★★**。
