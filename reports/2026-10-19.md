9. **爆发原因**：依据 README、许可证、近期提交、Issue 与榜单表现作分析推断，不代表维护者官方结论。

## 项目分析

### 1. MadsLorentzen/ai-job-search

- **主要用途**：把职位发现、匹配评分、定制简历与求职信、申请跟踪和面试准备组织成可本地运行的 Agent 求职工作流。
- **技术栈**：Python 3.10+、Claude Code/Agent Skills、Bun、LaTeX、PDF 可解析性检查；MIT。
- **近期增长及口径**：约 **+2,213 Star/24h、+5,742 Star/7d**，相对日增约 **4.4%**。当前 53,078 Star、17,352 Fork，Fork 较上期约 +434；由第二升至第一。
- **贡献与讨论**：近 7 天约 52 次提交、作者身份缺失、22 个新 Issue；最新修复 Freehire 搜索端点、User-Agent 联系标识和被误提交的 `node_modules` 路径。
- **爆发原因**：项目把“AI 写简历”扩展成可 Fork、可审查、可落地的全流程求职系统，真实职位源与材料校验持续完善，形成强烈传播和复用信号。
- **亮点**：drafter-reviewer 双阶段写作、LaTeX/PDF 输出、职位门户 Skill、薪资基准、申请追踪和面试准备组成闭环。
- **潜在风险**：`/setup` 可能把姓名、联系方式、履历和薪资预期写入 Git 历史，应使用私有仓库并检查历史；职位站点条款、模型幻觉与招聘公平性也需评估。最终材料必须人工核验且不得虚构经历。
- **适合人群与关注程度**：希望结构化个人求职流程、研究垂直 Agent 或构建职业服务工具的团队；**★★★★★**。

- **主要用途**：全本地语音工作站，覆盖声音克隆、声音设计、视频配音、听写、转录、有声书、批处理以及 Agent API/MCP。

- **亮点**：模型管理、批量任务、监控文件夹、recipe、API/MCP 和跨设备客户端形成完整产品面，而非单一推理脚本。
- **潜在风险**：模型权重、声音样本与输出权利受各自条款约束，声音克隆必须取得授权；AGPL 网络服务与分发义务需要提前评估。Issue 中出现疑似恶意“安装修复”推广，不能运行未经验证的第三方命令。

- **亮点**：并行 worktree、终端分屏、AI diff、移动伴侣、SSH worktree 和脚本化 CLI，形成多 Agent IDE 的完整雏形。

### 10. Comfy-Org/ComfyUI

- **主要用途**：基于节点图的生成式 AI 内容创作引擎、GUI、API 与后端，支持图像、视频、音频等扩散工作流及可复用节点生态。
- **技术栈**：Python、PyTorch、前端节点图、GPU 推理、插件/自定义节点与 API；GPL-3.0。
- **近期增长及口径**：约 **+155 Star/24h**，相对日增约 **0.11%**；7 天直接值缺失。当前 138,589 Star、16,502 Fork；新上榜第十。

- **爆发原因**：节点式生成工作流继续从图像扩展到视频、音频和 Agent 可调用后端；成熟生态与快速模型适配使其即使在大基数下仍能进入日榜。
- **亮点**：可组合工作流、局部重算、低显存优化、API 模式和庞大自定义节点生态，使研究原型与创作生产可以共享同一图结构。
- **潜在风险**：第三方自定义节点可执行任意 Python 代码，是主要供应链入口；模型许可证、内容权利、GPU 资源和工作流兼容性需单独管理。GPL-3.0 的分发义务也需评估。
- **适合人群与关注程度**：生成式图像/视频/音频、节点式工作流、模型适配和本地推理平台团队；**★★★★☆**。
