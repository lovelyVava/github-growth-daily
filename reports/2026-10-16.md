## 统计口径与限制

1. **24 小时新增 Star**：采用 GitHub Trending 日榜的 `stars today`，属于滚动窗口，不等于自然日或相邻累计快照差；报告按该值重新排序。
2. **7 天新增 Star**：采用 GitHub Trending 周榜的 `stars this week`。本期主榜只有 `REA` 与 `Ghidra` 有直接值；其余标为“缺失”，不以短周期累计快照差冒充完整 7 天窗口。
3. **当前 Star/Fork**：采用 2026-10-16 08:08 前后的 GitHub Trending 与仓库 API 快照，分钟级差异可能造成少量偏差。
4. **Fork 较上期**：只对连续上榜且上期存在同口径快照的项目计算；新上榜项目标为“缺失”。
5. **工程活跃度**：统计 2026-10-09 00:00 UTC 起约 7 天默认分支提交；单仓库最多读取 100 条，达到上限记为 `≥100`。
6. **作者身份**：优先按提交关联的 GitHub 登录名去重，缺失时使用提交作者邮箱或名称；机器人、合并提交和共同作者会造成偏差，不等同于完整贡献者人数。
7. **讨论热度**：统计同一窗口新建 Issue，使用 `is:issue` 排除 PR；自动化工单、路线图拆分和模板化提交可能放大数量。
8. **开源范围**：主榜要求存在可验证的标准开源许可。`VoiceStudio` 为 AGPL-3.0；网络服务分发修改版时需要履行相应源码义务。
9. **爆发原因**：依据 README、许可证、近期提交、Issue 与榜单表现作分析推断，不代表维护者官方结论。

## 项目分析

### 1. morluto/rea

- **主要用途**：通过统一 MCP/CLI 对网站、JavaScript/Electron 应用、.NET 程序、APK、固件、数据库与原生二进制进行证据化逆向分析。
- **技术栈**：TypeScript、Node.js 22+、MCP、Hopper/Ghidra/IDA、JADX、Binwalk/Unblob；MIT。
- **近期增长及口径**：约 **+32,314 Star/24h、+239,477 Star/7d**，相对日增约 **13.6%**。当前 269,546 Star、67,575 Fork，Fork 较上期约 +7,592；连续第一。
- **贡献与讨论**：近 7 天提交 **≥100**、约 8 个作者身份、1,291 个新 Issue；最新修复集中在 Ghidra 失败状态保留、JavaScript rest-array 键、Go 依赖覆盖语义和 Claude 配置路径。
- **爆发原因**：它把网页行为、反编译器、固件与原生二进制统一为 Agent 可调用的证据链，持续扩张的适配面叠加“逆向任何东西”的强叙事，形成异常集中的传播。
- **亮点**：输出附带证据、覆盖状态和未知项；近期继续处理分析完整性与失败状态，降低缺失数据被误认为确定结论的风险。
- **潜在风险**：明显双重用途，只能分析获授权目标。安装脚本、浏览器捕获、反编译器和 MCP 权限会扩大供应链、隐私与主机安全面；异常涨星和 1,291 个新 Issue 都应与真实活跃用户、可维护性和部署成熟度分开判断。
- **适合人群与关注程度**：获授权的软件审计、兼容性研究、恶意样本隔离分析和企业逆向 Agent 团队；**★★★★★**。

## 当天技术趋势

1. **Agent harness 与 Skill 生态占据主流。** `ECC`、`Superpowers`、`Claude Code Plugins`、`Ruflo`、`scientific-agent-skills` 和 `Caveman` 都在争夺“模型之外”的执行与规范层，热点已从单一编码能力转向技能分发、方法论、编排和治理。
2. **上下文效率成为独立产品类别。** `XERJ` 从检索侧减少整文件读入，`Caveman` 从输出、日志和网页侧压缩 token；两者都说明优化对象正在从模型参数转向证据选择和信息密度。
3. **逆向 Agent 带动成熟底座回潮。** `REA` 继续贡献近八成日增，`Ghidra` 同时出现日榜和周榜并保持 70 次周提交；新式 Agent 外壳正把注意力传导到老牌分析器。
4. **安全与供应链风险随插件化同步上升。** 官方插件目录仍明确要求逐个信任评估；ECC、Superpowers、Ruflo 的 Skills、Hooks、MCP 和 GitHub App 都可能继承用户权限。安装方便不能替代固定版本、审查来源和最小权限。
5. **增长质量分化明显。** `scientific-agent-skills` 日增超过 1,000，但周内仅一次自动提交；相反 `XERJ`、`ECC` 和 `Ghidra` 同时具备提交、作者与 Issue 信号。热榜只能衡量注意力，工程决策必须看多维结构。
