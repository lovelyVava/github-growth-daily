## 统计口径与限制

1. **24 小时新增 Star**：采用 GitHub Trending 日榜的 `stars today`；这是滚动窗口，不等于自然日或相邻快照差。页面顺序不严格按该值排序，本报告按数值重新排序。
2. **7 天新增 Star**：采用周榜的 `stars this week`。只有公开周榜直接展示的数值才写入；未进入周榜的项目标为“缺失”，不从累计 Star 反推。
3. **当前 Star/Fork**：采用 2026-09-13 08:00–08:10 的 GitHub API 快照。Trending 与 API 抓取时间略有不同，因此累计数可能存在小幅时差。
4. **Fork 变化**：仅对连续进入前十的项目比较 9 月 12 日与 9 月 13 日相邻快照；新上榜或重新上榜项目不估算 24 小时 Fork 变化。
5. **工程活跃度**：统计 2026-09-06 00:00 UTC 起约 7 天的默认分支提交，单仓最多读取 100 条；触及上限写作“≥100”。
6. **贡献者活跃度**：按提交记录中的 GitHub 账号或作者邮箱去重估算，可能拆分同一人的多个身份或包含机器人；截断仓库写作下限，不等同累计 Contributors。
7. **讨论热度**：统计同一窗口新建 Issue，排除 PR。若接口首 100 条记录仍全部落在窗口内，则写作下限；Issue 数量不等于有效人工讨论。
8. **开源口径**：优先纳入具有明确 OSI 兼容许可证的代码仓库。`YuE` 的代码为 Apache-2.0，但模型权重为 CC BY-NC 4.0；`iloader` 的代码为 MIT，但品牌资产另受限制；均在风险项中单独说明。
9. **爆发原因**：根据 README、近期活动与榜单表现作分析推断，不代表维护者官方结论。

## 项目分析

### 1. bilawalsidhu/gods-eye-view

- **主要用途**：在浏览器 3D 地球上统一展示航班、船舶、卫星、地震、火情、交通、公共摄像头和无线电等开放信号，并支持语音控制与场景分析。
- **技术栈**：JavaScript、Vite、Cesium/WebGL、GLSL、公开地理与遥测 API、可选 OpenAI 实时语音 Agent；代码采用 MIT License，数据与 3D 资产另行授权。
- **近期增长**：日榜约 **+2,265 Star**、周榜约 **+10,510 Star**；相对日增约 **8.2%**。当前 29,845 Star、6,013 Fork；较上期 Fork 约 **+471**，排名保持第一。
- **贡献与讨论**：近 7 天提交 **≥100**、作者身份 **≥12**、新 Issue **≥24**；提交与 PR 均触及读取上限，工程活跃度强。
- **爆发原因**：逼真的“情报驾驶舱”视觉效果、真实公开数据、无需密钥的快速体验和持续更新共同维持传播。
- **亮点**：模块化图层、目标跟踪、轨迹与视域、分享链接、语音白板；真实数据与模拟数据有区分标记。
- **潜在风险**：TeleGeography 等第三方数据或资产有非商业、署名和再分发限制；公开摄像头及位置数据存在隐私、误读与双重用途风险；浏览器端 Key 必须限制来源。
- **适合人群**：GIS/OSINT 教学、实时可视化、灾害与交通演示，以及需要 3D 地理交互原型的开发者。
- **值得关注程度**：**★★★★☆**。七日动量和工程活动都很强，但商业部署前必须逐项审计数据、资产和伦理边界。

- **主要用途**：从歌词与风格提示生成可编辑的旋律/和弦计划，再合成长篇人声与伴奏；也支持零样本翻唱和通过 Agent 编辑歌曲结构。
- **技术栈**：Python 3.12、AR–NAR Mixture-of-Transformers、符号规划、语义 Token、Flow Matching、VAE、CUDA/BF16；代码与 Skill 为 Apache-2.0，模型权重为 CC BY-NC 4.0。

- **亮点**：白盒符号规划、计划复用、48 kHz 立体声、分阶段 Python API 与 Agent Skill；README 提供公开基准和试听样例。
- **潜在风险**：官方要求 NVIDIA BF16 GPU 与约 24 GB VRAM；模型权重禁止商业使用；翻唱和训练/输入素材可能涉及声音、歌词与作品版权；基准结论仍需独立复现。
- **适合人群**：音乐生成、可控多模态模型、符号音乐、音频编辑与 Agent 创作流程研究者。
- **值得关注程度**：**★★★★☆**。方法和交互形态值得深入研究，商业应用受权重许可证明显限制。
