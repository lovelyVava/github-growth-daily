3. **Fork 变化**：对连续上榜项目使用 9 月 7 日与 9 月 8 日相邻快照差；新上榜或重新上榜项目不估算 24 小时 Fork 变化。
4. **工程活跃度**：统计 2026-09-01 00:00 UTC 起约 7 天的默认分支提交，单仓最多读取 100 条；`HyperFrames` 触及上限，写作“≥100”。
5. **贡献者活跃度**：按提交记录中的去重作者邮箱估算，可能把同一人的多个邮箱拆开，也可能包含机器人；截断仓库写作下限。该值不等同仓库累计 Contributors。
6. **讨论热度**：使用 GitHub Issue Search 统计同窗口新建 Issue；未把 PR 混入。Issue 数量表示参与或维护压力，目录投稿、自动报告等需要结合内容解释。
7. **许可证**：以根目录 `LICENSE` 优先于 README 徽章或文字。`LunaTV` 根许可证为 CC BY-NC-SA 4.0，与 README 的 MIT 表述冲突，报告按更严格的根许可证处理。
8. **爆发原因**：根据 README、近期活动与榜单表现作分析推断，不代表维护者官方结论。

### 1. affaan-m/ECC

- **主要用途**：为 Claude Code、Codex、OpenCode、Cursor 等编码 Agent 提供 Skills、Hooks、记忆、安全扫描、研究优先流程和性能优化工具。

- **近期增长**：日榜约 **+1,897 Star**、周榜约 **+7,735 Star**；相对日增约 **0.76%**。当前 252,820 Star、37,925 Fork；较上一期 Fork 约 **+149**，排名上升 2 位。
- **贡献与讨论**：近 7 天约 52 次提交、约 6 个作者身份、14 个新 Issue，工程活动较上一窗口进一步增强。
- **爆发原因**：用户开始追求跨宿主同步、持续记忆、质量门与供应链防护，ECC 将这些能力组合成统一 Agent 工程体系。
- **亮点**：大量专用 Agent 与 Skills、多宿主适配；安全、测试、审查和研究流程整合度高。
- **潜在风险**：不同宿主能力不等价；大量 Hooks/Skills 增加权限、上下文和维护负担；快速更新使版本知识易过期。

### 2. microsoft/markitdown

- **主要用途**：把 PDF、Office、图片、音频、HTML、ZIP、邮件、电子书等内容转为适合 LLM 和文本分析管线消费的结构化 Markdown。
- **技术栈**：Python 3.10+、CLI/Python API、按格式拆分的可选依赖、第三方插件、可选 Azure Document Intelligence/Content Understanding；MIT License。
- **近期增长**：日榜约 **+886 Star**；周榜值缺失；相对日增约 **0.49%**。当前 180,173 Star、13,260 Fork；新上榜，24 小时 Fork 变化缺失。
- **贡献与讨论**：近 7 天约 49 次提交、约 33 个作者身份、16 个新 Issue；贡献广度很强。
- **爆发原因**：RAG、Agent 与代码审查越来越需要把异构附件转为可检索文本；MarkItDown 的轻量本地转换、插件和云端高质量解析覆盖多档需求。
- **亮点**：保留标题、列表、表格和链接；依赖可按格式安装；OCR 插件和多模态云解析可补充扫描件、复杂表格与音视频。
- **潜在风险**：项目明确提醒转换过程拥有当前进程的 I/O 权限；不可信 URL、压缩包或文档可能引入 SSRF、路径访问和解析器风险；输出面向机器消费，不保证高保真人类排版。
- **适合人群**：RAG、知识库、企业代码审查、附件取证、文档归档和多模态预处理团队。
- **值得关注程度**：**★★★★★**。对现有 Open Code Review 的 PDF/Office 证据链和文档路由尤其有落地价值。

- **爆发原因**：“开箱即用、无账号、无追踪”的反注册墙定位清晰，目录形式易分享，表单投稿放大社区参与。

- **值得关注程度**：**★★★★☆**。连续增长强，但长期价值取决于审核质量而非收录数量。

## 当天技术趋势

1. **文档转换重新成为 Agent 基础设施焦点**：`MarkItDown` 位列第二，且 49 次提交来自约 33 个作者身份，说明把 PDF、Office、图片和音视频安全转为 Markdown，正在成为 RAG 与证据链的共享底座。
2. **“网页即视频”把 Agent 内容生成带入确定性渲染**：`HyperFrames` 用 HTML/CSS 和可定位动画输出 MP4，相比纯生成式视频更便于复现、审查和逐帧修改。

4. **大型 Harness 的竞争转向控制面与可运维性**：`ECC`、`Ruflo`、`deer-flow` 分别强调跨宿主规则、群体编排和生产沙箱；真正差异正在变成权限、记忆、失败回放、资源上限和审计。
5. **Star 热度与项目状态可能背离**：`openai/skills` 在已弃用状态下仍新上榜，`LunaTV` 在近期无提交且许可证冲突时仍获增长。选型不能只看日榜。
