## 项目分析

### 1. morluto/rea

- **主要用途**：通过统一 MCP/CLI 对网站、JavaScript/Electron 应用、.NET 程序、APK、固件和原生二进制进行证据化逆向分析。
- **技术栈**：TypeScript、Node.js 22+、MCP、Hopper/Ghidra/IDA、JADX、Binwalk/Unblob；MIT。
- **近期增长及口径**：约 **+54,706 Star/24h**，相对日增约 **36.1%**；7 天直接值缺失。当前 206,274 Star、50,240 Fork，Fork 较上期约 +14,407；连续第一。
- **贡献与讨论**：近 7 天提交 **≥100**、约 61 个作者身份、714 个新 Issue；最新修复 Ghidra 函数面与调用覆盖信息丢失，并继续收紧 JVM 架构、Electron 启动和完整性策略边界。
- **爆发原因**：它把浏览器行为、反编译器、固件与原生二进制统一为 Agent 可调用的证据链，覆盖面、协作人数和实际修复同步增长；同时也形成了极强的社交传播效应。
- **亮点**：静态与动态分析并存，能够把函数、调用关系、快照与比较结果保存为可复核证据；近期改动集中在“不把缺失数据误报为完整结论”，这对企业审计尤其重要。
- **潜在风险**：明显双重用途，只能分析获授权目标。浏览器捕获、反编译器、安装脚本和 MCP 权限会扩大供应链、隐私和主机安全面；714 个新 Issue 代表极高支持压力。异常高速涨星也应与真实部署、留存和安全成熟度分开判断。
- **适合人群与关注程度**：获授权的软件审计、兼容性研究、恶意样本隔离分析和企业 `reverse-skill` 团队；**★★★★★**。

### 8. vercel-labs/skills

- **主要用途**：面向开放 Agent Skills 生态的安装、更新、同步和临时使用 CLI，可从 GitHub、GitLab、Azure Repos、任意 Git URL 或本地路径分发 Skill。
- **技术栈**：TypeScript、Node.js、npm/npx、Git、GitHub CLI 与多 Agent 目录适配；MIT。
- **近期增长及口径**：约 **+187 Star/24h**，相对日增约 **0.55%**；7 天直接值缺失。当前 34,478 Star、2,952 Fork；新上榜第八。
- **贡献与讨论**：近 7 天 36 次提交、8 个作者身份、47 个新 Issue；近期发布 v1.7.2，加入工作区递归同步，并修复锁定路径与镜像 Skill 的更新行为。
