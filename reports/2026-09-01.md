7. **爆发原因**：依据 README、近期版本、活动变化和榜单表现作分析推断，不代表维护者官方结论。

## 项目分析

### 1. tt-a1i/archify

- **主要用途**：让 Agent 把代码库或系统描述转成可交互、可验证的架构图、工作流图、时序图、数据流图和生命周期图。
- **技术栈**：JavaScript、Node.js CLI、typed JSON IR、自包含 HTML/SVG、Agent Skill；MIT License。
- **近期增长**：日榜约 **+3,993 Star**，周榜约 **+18,103 Star**；相对日增约 **11.6%**。当前 38,360 Star、2,458 Fork；较上一期 Fork 约 **+296**。
- **贡献与讨论**：近 7 天约 52 次提交、53 个新 Issue；独立贡献者、PR 与 Discussions 增量缺失。热度与高密度迭代仍同步。
- **爆发原因**：typed IR、确定性校验、源码证据和 Before/Delta/After 对比持续击中 Agent 图表“好看但不可审查”的痛点。
- **亮点**：事实层与展示层分离；生成物可校验、可修复、可导出；支持多语言、架构差异和可复现证据。
- **潜在风险**：模型化结果不等于真实运行拓扑；动态调用和配置依赖可能漏检；复杂图验证收敛成本仍可能较高；分享内部架构前必须脱敏。
- **适合人群**：架构师、研发效能和代码审查团队、复杂代码库学习者。
- **值得关注程度**：**★★★★★**。连续五天第一，增长已形成持续趋势而非单日偶发。

## 今日技术趋势

1. **Skills 正从文档集合变成工程运行时**：`reverse-skill` 有授权门、路由规则、工具索引、证据链和回归测试；`ECC` 则加入 Hooks、记忆、验证和安全扫描。
2. **专用 Agent 工作台继续胜过通用聊天外壳**：`OpenMAIC` 围绕课程生产形成完整闭环，`open-seo` 围绕 SEO 数据和任务形成垂直工作流。
3. **证据与可审查性成为增长关键词**：`archify` 输出可校验图表，`reverse-skill` 输出证据路径，`patent-disclosure-skill` 保留版本和修订记录。
4. **本地模型研究出现两条相反路线**：`minimind` 用小模型降低学习门槛；`heretic` 研究安全对齐在表示空间中的可修改性。前者适合教学，后者需要更严格治理。

6. **安全工具供应链是共同风险**：安全 Skill、Hook、客户端补丁和模型修改工具都能执行高权限操作，安装来源、版本固定、沙箱和审计应成为默认门槛。

## 最值得深入研究的 3 个项目

### 1. zhaoxuya520/reverse-skill

**理由**：它把安全 Agent 最难治理的四件事——授权范围、任务路由、工具供应链和证据链——放进同一个可回归框架；日增约 1,439 Star，且有真实提交活动支撑。

**建议验证**：抽取 20 个路由案例检查误路由率；确认无授权或网络配置缺失时是否失败关闭；检查自动安装是否固定版本和校验哈希；随机复核报告中 Evidence→Finding→Path 是否可从原始产物重建。

### 2. affaan-m/ECC

**理由**：近 7 天提交达到搜索上限，说明它不只是大型提示词仓库，而是快速演化的 Agent harness。计划、测试、审查、记忆和 AgentShield 的组合对编码 Agent 治理很有借鉴价值。

**建议验证**：在一个中型仓库做开启/关闭 ECC 的 A/B 测试，对比 token、耗时、测试通过率、误改率和审查缺陷；审计 Hooks、MCP、权限、记忆落盘与多宿主能力差异；避免一次启用全部 Skills。

### 3. THU-MAIC/OpenMAIC

**理由**：日增约 2,819、相对增长约 11.8%，并有 24 次提交和 31 个新 Issue。它展示了如何把多 Agent、Skills、材料、持久化、编辑与多媒体做成可使用的垂直产品。

**建议验证**：同一主题重复生成并比较事实正确率、课程层级、引用、测验覆盖和成本；测试断网、本地模型、失败恢复和材料权限；检查导出结果是否能被教师独立修改与追踪来源。
