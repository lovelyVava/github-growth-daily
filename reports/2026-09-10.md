## 统计口径与限制

1. **24 小时新增 Star**：采用 GitHub Trending 日榜的 `stars today`；这是滚动窗口，不等于自然日或相邻快照差。页面顺序不严格按该值排序，本报告按数值重新排序。
2. **7 天新增 Star**：采用周榜的 `stars this week`。只有公开周榜直接展示的数值才写入；未进入周榜的项目标为“缺失”，不从累计 Star 反推。
3. **当前 Star/Fork**：采用观察时点 GitHub API 快照。Trending 页面、API 与报告抓取时间略有不同，因此累计数可能与榜单页面存在小幅差异。
4. **Fork 变化**：仅对连续进入前十的项目比较 9 月 9 日与 9 月 10 日相邻快照；新上榜和重新上榜项目不估算 24 小时 Fork 变化。
5. **工程活跃度**：统计 2026-09-03 00:00 UTC 起约 7 天的默认分支提交，单仓最多读取 100 条；触及上限写作“≥100”。
6. **贡献者活跃度**：按提交记录中的去重作者邮箱估算，可能拆分同一人的多个邮箱或包含机器人；截断仓库写作下限，不等同累计 Contributors。
7. **讨论热度**：统计同一窗口新建 Issue，排除 PR。Issue 数量只代表活动信号，不代表问题严重程度或有效人工讨论。
8. **开源口径**：`system-design-notes` 与 `openai/plugins` 没有明确仓库许可证，严格说属于源码公开但授权缺失；因增长信号显著保留观察，并明确降权。
9. **爆发原因**：根据 README、近期活动和榜单表现作分析推断，不代表维护者官方结论。

## 项目分析

### 1. ayghri/i-have-adhd

- **主要用途**：为编码 Agent 提供“先给行动、限制旁支、短列表、明确下一步”的输出规则，减少答案埋在长篇解释中的情况；无需用户具有 ADHD 诊断。
- **技术栈**：Python、Markdown Skill、Hooks，以及 Claude Code、Codex、Cursor、OpenCode、Gemini、Kimi、Qwen 等多宿主插件配置；MIT License。
- **近期增长**：日榜约 **+4,624 Star**、周榜约 **+5,927 Star**；相对日增约 **15.46%**。当前 34,529 Star、2,021 Fork；重新进入前十并排名第一。
- **贡献与讨论**：近 7 天约 2 次提交、约 2 个作者身份、6 个新 Issue；涨星远强于工程活动。
- **爆发原因**：编码 Agent 输出越来越长，用户对“直接告诉我下一步”的需求强烈；规则简单、可复制、多宿主适配，使传播门槛极低。
- **亮点**：10 条规则可读性强，强调行动优先、最多五项、每轮重述状态、使用具体时间估算和可见进展。
- **潜在风险**：过度压缩可能省略前提、风险和边界；医疗化命名容易让人误把交互偏好当作诊断；不同任务需要不同信息密度。
- **适合人群**：容易被长回答淹没的学习者、开发者，以及需要短步骤和明确下一动作的 Agent 团队。
- **值得关注程度**：**★★★★☆**。很适合作为个人交互层试验，但不应覆盖安全、法律或复杂设计任务所需的完整解释。

### 2. cathrynlavery/diagram-design

- **主要用途**：让 Agent 生成可编辑、可验证、可导出的架构图、流程图、时序图、ER 图和数据流图等 38 类编辑式图表。
- **技术栈**：Agent Skills、Markdown 规则、自包含 HTML + SVG、可选无障碍动效、Mermaid/draw.io 导入；MIT License。
- **近期增长**：日榜约 **+2,286 Star**；周榜值缺失；相对日增约 **6.67%**。当前 36,561 Star、2,309 Fork；较上一期 Fork 约 **+110**，排名上升 2 位。
- **贡献与讨论**：近 7 天约 16 次提交、约 8 个作者身份、14 个新 Issue；多人协作和讨论继续增长。
- **爆发原因**：品牌适配、语义模式、静态默认与清晰导出解决 Agent 图表“能表达但难交付”的最后一公里。
- **亮点**：丰富图形语法、主题与品牌 Profile；静态 HTML 默认、无需构建；支持多种 Agent 宿主。
- **潜在风险**：视觉正确不等于语义正确；第三方市场自动更新需供应链治理；复杂图仍要人工核对节点、方向和数据来源。
- **适合人群**：架构师、产品经理、技术文档、代码审查报告，以及偏好图像辅助学习的用户。
- **值得关注程度**：**★★★★★**。增长、贡献广度和可交付价值同时较强。

## 当天技术趋势

1. **输出规则成为独立产品**：`i-have-adhd`、`superpowers` 和 `ECC` 分别从回答结构、研发方法和工程治理三层约束 Agent，说明竞争正在从模型能力转向可复用行为规范。
2. **团队级 Agent 配置进入 GitOps**：`teamai-cli` 用 Git/MR 分发 Skills、Rules、Hooks、MCP 和经验知识，比个人复制配置更适合审计、回滚和内网协作。
3. **本地 Agent 宿主开始产品化**：`PI-Desktop` 把模型接入、权限审批、长会话、代码审查和扩展市场集中到桌面端；这与本地模型、隐私和脱离 IDE 锁定的需求一致。
4. **视觉与架构资产继续代码化**：`diagram-design` 和 `awesome-gpt-image-2` 把图表、提示词和生成案例变成可版本控制、可组合的资产。
5. **热度与授权必须分开判断**：`system-design-notes` 和 `openai/plugins` 均有显著增长，但没有明确许可证；高 Star 不能补足法律授权。
6. **短期涨星不等于持续开发**：`PI-Desktop`、`teamai-cli`、`ECC` 和 `diagram-design` 有强提交信号；`system-design-notes`、`superpowers` 本窗口无默认分支提交，应分别看作内容传播或方法论回潮。
