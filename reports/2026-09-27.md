## 统计口径与限制

1. **24 小时新增 Star**：采用 GitHub Trending 日榜的 `stars today`，是滚动窗口，不等于自然日或相邻累计快照差；页面顺序不严格按数值排序，本报告按该值重排。
2. **7 天新增 Star**：采用周榜的 `stars this week`。只有直接进入周榜的项目列出；未进入周榜标为“缺失”，不从累计 Star 反推。
3. **开源范围**：主榜要求仓库整体具有可识别的标准开源许可证；今日十项分别采用 MIT、Apache-2.0、MPL-2.0 等 OSI 许可证。
4. **当前 Star/Fork**：采用观察窗口内 GitHub 页面/API 快照；分钟级抓取会产生少量差异。
5. **Fork 变化**：只对连续进入主榜、且上一期存在同口径快照的 5 个项目计算相邻快照差。新上榜与重新上榜项目不拿更早数据伪装成 24 小时增量。
6. **工程活跃度**：统计 2026-09-20 00:00 UTC 起约 7 天默认分支提交；最多读取 100 条。达到上限时记为 `≥100`。
7. **贡献者数限制**：本期提交搜索结果未可靠返回作者身份，故作者数统一标为“缺失”；不以 Trending 展示的少量头像代替完整贡献者计数。
8. **讨论热度**：统计同一窗口新建 Issue，使用 `is:issue` 排除 PR；达到 100 条读取上限时记为 `≥100`。数量会受机器人、模板和维护者拆分影响，需结合标题判断质量。
9. **爆发原因**：依据 README、近期提交、Issue 和榜单表现作分析推断，不代表维护者官方结论。

## 项目分析

### 1. paperclipai/paperclip

- **主要用途**：把多个 AI Agent 组织成可审计的“虚拟公司”，统一管理目标、任务、组织结构、权限、预算、审批、心跳和执行记录。
- **技术栈**：TypeScript、Node.js、React、数据库迁移、浏览器测试与跨 Agent 适配；MIT。
- **近期增长及口径**：约 **+2,608 Star/24h、+5,376 Star/7d**；相对日增约 **3.1%**。当前 87,252 Star、15,426 Fork，Fork 较上期约 +196；连续第一且日增继续扩大。
- **贡献与讨论**：近 7 天默认分支提交 **≥100**、作者数缺失、新 Issue **≥100**。最新提交强化 CLI 鉴权 challenge ID 校验、代理拒绝诊断边界和个人快捷键偏好。
- **爆发原因**：团队从并排运行多个 Agent 转向组织级调度、预算和审计；Paperclip 以熟悉的任务看板与组织结构降低控制面理解成本。
- **亮点**：跨模型适配、预算与停止门禁、人工审批、任务—目标追溯、审计日志和多组织隔离形成较完整的运营闭环。
- **潜在风险**：Issue 报告运行去重与环境租约泄漏、终端访问失败、评论提交静默丢失和唤醒后的写权限上下文陈旧。它掌握 Agent、凭据和预算，必须验证重启幂等、权限收敛、强制停止与 Secret 隔离。
- **适合人群与关注程度**：多 Agent 平台、AI 原生团队和长时任务运营团队；**★★★★★**。

## 当天技术趋势

1. **多 Agent 控制面仍是最强主线**：`Paperclip` 连续第一且工程与讨论双双达到读取上限。竞争焦点已从“能否并行调用”转向组织、预算、审批、恢复和问责。
2. **长期记忆进入成本与一致性阶段**：`Hindsight` 周增约 7,282 Star，但高热度 Issue 直指超长上下文、重复摄取和刷新失败；召回率必须与 Token 上限、删除语义和污染恢复一起评估。
3. **Agent 凭据治理开始获得独立关注**：`OpenBao` 从榜外观察进入第五。Agent 平台连接代码库、云资源和移动设备后，动态 Secret、短租约、撤销与审计不再是可选附件。
4. **可编辑 Office Runtime 持续升温**：`Univer` 升至第三并进入周榜。表格、文档与演示既是 Agent 产物，也是人工验证和差异审查界面。
5. **模型优化的相对增速高于传播规模**：`Model Optimizer` 以约 8.1% 的相对日增领跑；量化和蒸馏正在从单点脚本变成有诊断、搜索和多 Runtime 输出的工程链路。
6. **Agent 协作趋向统一事件日志**：`Buzz` 把人、Agent、Git、工作流和审批放入同一签名事件模型，反映团队希望减少跨工具拼接；但移动端和审批门禁仍处早期。
7. **操作 Agent 从桌面扩展到真机**：`mobile-mcp` 的 Accessibility-first 路径降低 iOS/Android 自动化成本，同时把隐私、凭据和设备权限风险推到前台。
8. **安全 Skills 仍有强传播力**：`reverse-skill` 重新上榜，但双用途能力、命令执行与外部工具下载意味着采用门槛应是授权、沙箱和供应链审计，而不是 Star 数。
9. **成熟基础设施也会被低阈值日榜重新采样**：`VS Code` 的 +95 Star 并非爆发，却以提交和 Issue 双上限展示真实维护强度；今日排名不能等同于项目生命周期阶段。
