## 项目分析

### 1. elementalsouls/Claude-BugHunter

- **主要用途**：为 Claude Code 提供漏洞挖掘与外部红队 Skill 包，覆盖 24 类漏洞、企业身份和基础设施攻击矩阵。
- **技术栈**：Python、Shell/PowerShell、Claude Code Skills、漏洞模式库、命令行引擎与报告模板；MIT。
- **近期增长及口径**：约 **+1,803 Star/24h**，较上一期加速 181；11 月 14 日以来快照净增约 +10,601，采集时 16,432 Star、约 1,900 Fork。
- **贡献与讨论**：近七日约 81 次提交、12 个新议题；最新集中修复 triage 门禁、报告 BOM/CRLF、Windows 控制台及 HackerOne `--program` 查询。
- **爆发原因（推断）**：将大量已披露漏洞模式包装为 Agent 可调用技能，能快速构建侦察、验证、报告和平台对接流程。
- **亮点**：漏洞覆盖和报告模板结构化程度高，且在传播加速时仍保持大量实质修复。
- **潜在风险**：只能用于明确授权范围；误报、漏报、敏感信息落盘、攻击性命令误用及平台封禁风险都需要控制。
- **适合人群与关注程度**：经授权的渗透测试、Bug Bounty、AppSec 与红队研究人员；**★★★★☆**。

### 2. firecrawl/firecrawl

- **主要用途**：为 Agent 提供搜索、抓取、结构化抽取、浏览器交互及 550 多个数据源的统一知识入口。
- **技术栈**：TypeScript/Node.js、爬虫与浏览器、队列、PDF/HTML 转 Markdown、REST API、SDK 与自托管组件；AGPL-3.0。
- **近期增长及口径**：约 **+1,006 Star/24h**；11 月 19 日以来净增约 +2,961。当前 207,010 Star、10,815 Fork，Fork +41，连续第二。
- **贡献与讨论**：近七日约 85 次提交、18 个新议题；问题深入 Cloudflare 挑战页误收、Markdown 内容协商、PDF、robots 延时与自托管安装。
- **爆发原因（推断）**：Agent 的瓶颈继续从模型转向新鲜、可解析、可引用且合规的数据摄取，统一抓取与 Provider 接口具有平台价值。
- **亮点**：覆盖网页、PDF、浏览器和结构化抽取，同时提供托管及自托管路径；涨星与持续提交同步。
- **潜在风险**：AGPL 对网络服务部署有源码义务；抓取受 robots、版权、站点条款和隐私约束，SSRF、挑战页识别、队列成本与数据保留必须审计。
- **适合人群与关注程度**：RAG、Agent 知识摄取、搜索、数据管道和自托管平台团队；**★★★★★**。

### 3. mvanhorn/last30days-skill

- **主要用途**：聚合 Reddit、X、YouTube、Hacker News、Polymarket 与 Web 的近期内容，生成带来源和互动信号的研究摘要。
- **技术栈**：Python、站点/API 搜索、浏览器 Cookie、转录抓取、Agent Skill 与多宿主适配；MIT。
- **近期增长及口径**：约 **+560 Star/24h、+4,198 Star/7d**；当前 72,580 Star、6,419 Fork，重新上榜第三。

- **亮点**：时间窗口明确、跨平台，并把互动强度和来源带入综合结果；日增、周增、提交三类信号同时成立。
- **潜在风险**：受站点条款、Cookie、API 配额与反爬影响；社交信号可被操纵，来源授权、隐私和事实核验不能省略。

### 5. kajisho5/ffmpeg-skill

- **主要用途**：为 Claude Code、Cursor、Codex 等 Agent 提供本地视频剪辑、字幕、画幅、响度和平台导出能力。
- **技术栈**：Python、FFmpeg/FFprobe、Whisper、MCP Server、机器可读工具契约与 npm 安装入口；MIT。
- **近期增长及口径**：24 小时直接值缺失；约 **+3,598 Star/7d**，相对周增约 62%。当前约 9,400 Star、843 Fork，Fork +24，由第八升至第五。
- **贡献与讨论**：近七日提交 **≥100**、61 个新议题；新增多音轨语言标签，问题涉及 FFmpeg 9 HDR 色彩标签、偶发卡死、GPU 路径和自动化守卫。
- **爆发原因（推断）**：视频 Agent 的真实门槛是把复杂 FFmpeg 参数封装为可发现、可组合、可验证的本地工具契约。
- **亮点**：无需云 API Key，覆盖从探测到交付，可用 FFprobe 验证输出，适合隐私视频和批处理。
- **潜在风险**：极高提交与议题量说明接口和边界快速变化；编解码器、时间基、HDR、GPU 路径及本地文件权限必须隔离验证。
- **适合人群与关注程度**：短视频自动化、媒体流水线、字幕音频处理与 MCP/Agent Tool 开发者；**★★★★★**。
