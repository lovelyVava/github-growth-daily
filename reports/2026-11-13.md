9. **开源范围**：主榜要求存在可验证的标准开源许可。仓库级许可不清楚或限制商业使用的项目不进入严格开源主榜。

## 项目分析

### 1. meta/astryx

- **主要用途**：Meta 开源的企业级设计系统，为人类开发者与编码 Agent 提供统一组件、主题、模板、文档与 CLI。
- **技术栈**：React 19、TypeScript、StyleX、CSS 自定义属性、Storybook、pnpm Monorepo；MIT，当前 Beta。
- **近期增长及口径**：日榜约 **+2,776 Star/24h**；连续可见快照 6 天净增至少 +11,471。当前 25,519 Star、1,986 Fork，Fork +133，连续第一。
- **贡献与讨论**：近 7 天提交 **≥100**、39 个新 Issue；近期新增 CLI 主题命令。讨论集中在弹窗幽灵输入、滑动闪烁、Lightbox 行为和富文本邮件自动链接正则性能。
- **爆发原因（推断）**：Meta 的规模背书、150+ 组件，以及“人和 Agent 使用同一套可预测 API/文档”的定位叠加，形成持续传播。
- **亮点**：组件、主题、模板、CLI、文档和可访问性测试形成完整交付链；预编译 CSS 降低消费者对 StyleX 构建插件的依赖。
- **潜在风险**：Beta API 与 React 19 门槛；快速提交与大量 Issue 表明接口仍在变化。处理不可信富文本前需验证正则退化风险。
- **适合人群与关注程度**：设计系统、前端平台、React、可访问性和 Agent UI 生成团队；**★★★★★**。

### 2. milind-soni/OpenMausBot

- **主要用途**：自托管多 Bot 聊天应用，让 Agent 在隔离虚拟机中使用浏览器、终端和文件工具。
- **技术栈**：TypeScript、Electron、Expo、Node.js、Docker/虚拟机、计算机操作 Agent；Apache-2.0。
- **近期增长及口径**：周榜约 **+9,257 Star/7d**；相邻快照约 +198/24h。当前 21,391 Star、2,987 Fork，Fork +93，由第七升至第二。
- **贡献与讨论**：近 7 天提交和新 Issue 均 **≥100**。近期问题包括虚假用量状态触发重启、故障转移忽略模型限制、共享 VM 等待与 S3 归档行为。
- **爆发原因（推断）**：多 Agent 对话、桌面/移动端和真实执行 VM 被整合成完整产品，比单一提示词或工具演示更容易持续传播。
- **亮点**：具备任务接力、真实执行环境、多端入口与连接器，适合研究长期任务编排。
- **潜在风险**：提交与工单双触顶意味着稳定性压力大；终端、浏览器、文件、网络和第三方凭据必须在 VM 层隔离，并验证故障转移不会越过模型或权限约束。
- **适合人群与关注程度**：自托管 Agent、桌面 AI、虚拟化和多 Agent 产品团队；**★★★★☆**。

### 3. NVIDIA/auto-ontology

- **主要用途**：从企业元数据生成语义本体与关系图，为 Agent 提供指标定义、SQL 校验、血缘与来源证据。
- **技术栈**：Python、FastAPI、Postgres、Next.js/React、MCP/CLI/API、数据库连接器与 NVIDIA NIM；Apache-2.0。
- **近期增长及口径**：周榜约 **+7,947 Star/7d**，相邻快照约 +193/24h。当前 11,989 Star、983 Fork，Fork +30，由第五升至第三。
- **贡献与讨论**：近 7 天仅 2 次提交但有 33 个新 Issue；讨论涉及 Athena、替代 Join 路径、AGE 投影和 scoped reset 遗留共享术语。
- **爆发原因（推断）**：企业 Agent 的瓶颈正在从“能否查询”转向“语义是否一致、结果能否追溯”，本体、血缘和审批因此成为数据控制面。
- **亮点**：把语义、关系、连接器、查询与答案证据链放在同一层，并通过 MCP 暴露给 Agent。
- **潜在风险**：错误本体或连接器结果会被放大为可信上下文；33 个 Issue 对 2 次提交表明需求快于修复。生产使用必须验证只读权限、RLS/CLS、人工审批与审计日志。
- **适合人群与关注程度**：企业数据平台、语义层、Text-to-SQL、RAG 和 Agent 治理团队；**★★★★★**。

### 4. vercel-labs/agent-desktop

- **主要用途**：让 AI Agent 通过操作系统无障碍树查看并操作 macOS、Windows 和 Linux 桌面应用。
- **技术栈**：Rust 原生 CLI、系统 Accessibility API、Node/npm 包装、MCP、跨平台输入与会话层；Apache-2.0。
- **近期增长及口径**：周榜约 **+7,772 Star/7d**，相邻快照约 +314/24h。当前 22,305 Star、1,657 Fork，约 +57 Fork，由第六升至第四。
- **贡献与讨论**：近 7 天约 7 次提交、27 个新 Issue；发布 v1.3.0。问题包括 macOS `list-apps` 超时、无障碍树节点预算、Windows 非 ASCII npm 路径和 MCP session 不可用。
- **爆发原因（推断）**：电脑操作从截图坐标转向结构化无障碍树，跨平台 CLI 让 Agent 更容易进入真实桌面工作流。
- **亮点**：结构化控件语义比像素坐标稳定、上下文更紧凑，也更便于做操作审计。
- **潜在风险**：无障碍权限通常能读取敏感界面并执行高影响操作；平台差异、不可访问控件、焦点漂移和会话隔离均可能导致误操作。
- **适合人群与关注程度**：电脑操作 Agent、桌面自动化、可访问性工具和沙箱平台团队；**★★★★★**。
