## 项目分析

### 1. meta/astryx

- **主要用途**：Meta 内部成长八年的开源设计系统，为开发者和编码 Agent 提供组件、主题、模板、文档与 CLI。
- **技术栈**：React 19、TypeScript、StyleX、CSS 自定义属性、Storybook、pnpm Monorepo；MIT，当前 Beta。
- **近期增长及口径**：约 **+3,108 Star/24h**；现有连续快照 5 天净增至少 +9,574。当前 23,622 Star、1,853 Fork，Fork +270，从第二升至第一。
- **贡献与讨论**：近 7 天提交 **≥100**、42 个新 Issue。讨论包含富文本自动链接正则在长 token 上出现二次方耗时、打印/PDF 和表格能力缺口。
- **爆发原因（推断）**：Meta 将支撑 13,000+ 应用、150+ 组件的内部体系公开，并把“人和 Agent 使用同一套 API/文档”作为核心卖点，品牌、规模与 Agent 叙事叠加。
- **亮点**：组件、主题、模板、CLI、文档和可访问性测试形成完整系统；消费者无需采用 StyleX 构建插件即可使用预编译 CSS。
- **潜在风险**：仍处 Beta 且要求 React 19；高频提交与大量缺口 Issue 说明接口和覆盖面仍在快速变化。富文本正则性能问题也应在处理不可信输入前修复。
- **适合人群与关注程度**：设计系统、前端平台、React、可访问性和 Agent UI 生成团队；**★★★★★**。

### 2. sherlock-project/sherlock

- **主要用途**：按用户名在大量社交网站检索同名账户，用于授权 OSINT、数字足迹调查和威胁情报侦察。
- **技术栈**：Python CLI、异步 HTTP、数据驱动的网站规则、PyPI/Docker；MIT。
- **近期增长及口径**：约 **+2,393 Star/24h**；5 天可见快照净增至少 +11,087。当前 109,413 Star、12,693 Fork，Fork +234，由第一降至第二。
- **贡献与讨论**：提交检索返回 0，但仓库元数据显示 11 月 10 日仍有 push，因此按“提交数据缺失”而非“零开发”处理；近 7 天 11 个新 Issue，多为站点支持和误报。
- **爆发原因（推断）**：成熟 OSINT 工具继续被安全社区集中传播，跨站用户名查询的演示效果直观；Fork 同步增加说明存在真实试用和规则定制。
- **亮点**：安装简单、站点覆盖广、结果可导出，适合快速建立调查线索。
- **潜在风险**：同名账户不等于同一自然人；站点规则变化会产生误报，且使用涉及隐私、骚扰、服务条款与司法辖区限制。
- **适合人群与关注程度**：授权 OSINT、品牌保护、威胁情报和数字取证团队；**★★★★☆**。

### 3. mattpocock/skills

- **主要用途**：为编码 Agent 提供 TDD、代码评审、故障诊断、领域建模、PR、规范实施等工程方法 Skill。

### 4. pingdotgg/t3code

- **主要用途**：在移动端、Web 和 Electron 桌面端统一查看与控制本机编码 Agent，是面向多设备的 Agent harness 控制面。
- **技术栈**：TypeScript、Electron、iOS/Android、Web、远程环境链接与多 Agent 会话；MIT。
- **近期增长及口径**：周榜约 **+11,979 Star/7d**；可靠 24 小时值缺失。当前约 56,100 Star、10,400 Fork，新上榜第四。
- **贡献与讨论**：近 7 天提交和新 Issue 均 **≥100**。问题涉及 Android 链接界面不可滚动、远程线程黑屏、GitLab MR 高频轮询和供应商限额刷新缓慢。
- **爆发原因（推断）**：编码 Agent 从单终端工具演进为可随时查看、切换和接管的长期任务，手机与桌面控制面正成为新的产品入口。
- **亮点**：将多 Agent、跨设备、会话与环境状态集中展示，适合管理长任务而不是反复连接单个终端。
- **潜在风险**：远程控制面能触及源码、终端、凭据和 CI；认证、设备绑定、会话撤销、端到端加密、后台轮询成本和错误环境执行都需单独威胁建模。提交与 Issue 双触顶也意味着稳定性压力大。
- **适合人群与关注程度**：多 Agent 开发者、远程开发、IDE/Agent 平台和安全团队；**★★★★☆**。

### 5. NVIDIA/auto-ontology

- **主要用途**：从企业元数据构建语义本体和关系图，为 Agent 提供指标定义、SQL 校验、血缘与来源证据。
- **技术栈**：Python、FastAPI、Postgres、Next.js/React、MCP/CLI/API、数据库连接器与 NVIDIA NIM；Apache-2.0。
- **近期增长及口径**：周榜约 **+9,621 Star/7d**，相邻日快照差约 +168。当前 11,571 Star、953 Fork，Fork +40，由第四降至第五。
- **贡献与讨论**：近 7 天 3 次提交、36 个新 Issue；问题包括 scoped semantic reset 可能遗留孤立术语、缺少“数据中不存在”结果和多数据库兼容性。
- **爆发原因（推断）**：企业 Agent 的竞争点从“能否查询”转向“语义是否一致、结论是否可验证”，本体、血缘和审批成为数据控制面。
- **亮点**：把语义、关系、连接器、查询与答案证据链放在同一层，并以 MCP 暴露给 Agent。
- **潜在风险**：错误本体或连接器结果会被放大为可信上下文；本周 36 个 Issue 对 3 次提交显示需求增长快于修复速度。生产使用必须验证只读权限、RLS/CLS、人工审批和审计日志。
- **适合人群与关注程度**：企业数据平台、语义层、Text-to-SQL、RAG 与 Agent 治理团队；**★★★★★**。

### 6. vercel-labs/agent-desktop

- **主要用途**：让 AI Agent 通过操作系统无障碍树查看并操作 macOS、Windows 和 Linux 桌面应用。
- **技术栈**：Rust 原生 CLI、操作系统 Accessibility API、Node/npm 包装、MCP、跨平台输入与会话层；Apache-2.0。
- **近期增长及口径**：周榜约 **+9,502 Star/7d**；可靠 24 小时值缺失。当前约 21,600 Star、1,600 Fork，重新上榜第六。
- **贡献与讨论**：近 7 天约 11 次提交、30 个新 Issue；问题涉及 macOS 大型无障碍树耗尽节点预算、Windows 非 ASCII npm 路径和 MCP session 创建后不可用。
- **爆发原因（推断）**：电脑操作从像素坐标和截图逐步转向结构化无障碍树，跨平台 CLI 让 Agent 更容易在真实桌面应用中执行任务。
- **亮点**：结构化控件语义比视觉坐标更稳定，也更适合审计和最小化模型上下文；与 MCP/CLI 的结合便于嵌入现有 Agent。
- **潜在风险**：无障碍权限通常能读取敏感界面并执行高影响操作；平台差异、不可访问控件、焦点漂移和会话隔离都可能导致误操作。必须使用最小权限、危险操作确认和隔离账户。
- **适合人群与关注程度**：电脑操作 Agent、桌面自动化、可访问性工具和沙箱平台团队；**★★★★★**。

- **爆发原因（推断）**：MCP 从开发工具扩展到家庭自动化后，用户能直接用自然语言创建场景、检查设备并修改配置，演示价值和实用性都很高。
- **亮点**：直接复用 Home Assistant 生态和实体模型，覆盖配置、查询、自动化与多语言使用场景。
- **潜在风险**：灯光、门锁、摄像头、传感器和自动化都属于真实世界权限；必须限制实体范围、区分只读与写操作、确认高风险动作并避免把长期令牌暴露给模型。重复集成还可能阻塞更新。
- **适合人群与关注程度**：Home Assistant、智能家居、MCP 工具和本地 AI 团队；**★★★★★**。

### 10. vercel-labs/agent-browser

- **主要用途**：让 AI Agent 通过命令行打开网页、读取可访问性树，并以元素引用执行点击、输入、下载和录制。
- **技术栈**：Rust 原生 CLI、Chrome DevTools Protocol、Node/npm 包装、后台 daemon、MCP/Skills；Apache-2.0。
- **近期增长及口径**：约 **+780 Star/24h、+3,606 Star/7d**。当前 49,439 Star、3,463 Fork，Fork +144，由第五降至第十。
- **贡献与讨论**：近 7 天 27 次提交、19 个新 Issue；问题涉及跨域 iframe 令会话卡死、keydown/keyup 键码不完整和 Lightpanda 恢复时遗漏 localStorage。
- **爆发原因（推断）**：浏览器操作正在从重型 SDK 转向 Agent 友好的短命令、文本快照与可恢复会话；跨平台二进制降低部署门槛。
- **亮点**：可访问性树输出紧凑、引用适合模型使用，并提供会话、录制、调试、权限与多浏览器后端。
- **潜在风险**：浏览器会接触 Cookie、密码、下载文件和第三方内容；网页提示注入、域名跳转与危险操作必须由 allowlist、确认策略、隔离 profile 和审计日志约束。
- **适合人群与关注程度**：浏览器 Agent、自动化测试、研究采集和沙箱平台团队；**★★★★★**。
