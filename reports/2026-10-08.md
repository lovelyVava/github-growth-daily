## 项目分析

### 1. morluto/rea

- **主要用途**：通过统一 MCP/CLI 对网站、JavaScript/Electron 应用、.NET 程序、APK、固件和原生二进制进行证据化逆向分析。
- **技术栈**：TypeScript、Node.js 22+、MCP、Hopper/Ghidra/IDA、JADX、Binwalk/Unblob；MIT。
- **近期增长及口径**：约 **+4,666 Star/24h**，相对日增约 **45.5%**；7 天直接值缺失。当前 14,915 Star、1,554 Fork，Fork 较上期约 +530；连续第一。
- **贡献与讨论**：近 7 天提交 **≥100**、10 个作者身份、117 个新 Issue；最新加入对历史 Web 网络捕获的检查能力。
- **爆发原因**：它把多类逆向工具包装为 Agent 可调用的调查流程，并要求输出证据、限制与未知项；持续高频迭代又把关注从“演示”推向“可用控制面”。
- **亮点**：覆盖静态与动态分析，能接入 Hopper/Ghidra/IDA；安装前展示变更并备份配置，适合设计可审计的逆向 Skill。
- **潜在风险**：明显双重用途；只能分析获授权目标。外部反编译器、安装脚本、浏览器捕获和 MCP 权限扩大供应链、隐私与主机安全面。
- **适合人群与关注程度**：获授权的软件审计、兼容性研究、恶意样本隔离分析和企业 `reverse-skill` 团队；**★★★★★**。

### 2. boykopovar/AnyPS5

- **主要用途**：把 PS5 可执行文件重链接为 Windows/Linux 原生格式，并实现系统 PRX 库与着色器重编译，不依赖独立模拟器进程。
- **技术栈**：C++、原生 Relinker、动态链接、SPIR-V、SDL 输入；GPL-2.0-only。
- **近期增长及口径**：约 **+2,725 Star/24h、+3,073 Star/7d**，相对日增约 **35.1%**。当前 10,490 Star、792 Fork，Fork 较上期约 +320；从第五升至第二。
- **贡献与讨论**：近 7 天提交 **≥100**、15 个作者身份、62 个新 Issue；最新合并一维图像数组收集能力。
- **爆发原因**：原生重链接路线与传统模拟器差异明显，兼容性地图、系统库与图形能力快速推进，带来持续的技术传播。
- **亮点**：公开兼容性和技术债，对不支持状态显式失败，着色器输出可用 SPIRV-Tools 验证。
- **潜在风险**：系统库和游戏支持仍不完整，用户必须确保二进制来源合法。虽然使用 SPIR-V，但不应据此假设 Radeon RX 7900 XTX/ROCm 路径已达到可用水平，需逐项验证 Vulkan/驱动兼容性。

- **潜在风险**：会话可能含源代码、终端输出和秘密信息；需验证数据生命周期、模型发送范围、删除策略、错误召回和记忆投毒。
- **适合人群与关注程度**：长期编码任务、企业代码知识库、Open Code Review 与 Agent 记忆评估团队；**★★★★★**。
