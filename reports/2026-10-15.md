## 统计口径与限制

1. **24 小时新增 Star**：采用 GitHub Trending 日榜的 `stars today`，属于滚动窗口，不等于自然日或相邻累计快照差；报告按该值重新排序。
2. **7 天新增 Star**：采用 GitHub Trending 周榜的 `stars this week`。本期主榜只有 `REA` 与 `Ghidra` 有直接值；其余标为“缺失”，不以短周期累计快照差冒充完整 7 天窗口。
3. **当前 Star/Fork**：采用 2026-10-15 08:00 前后的 GitHub Trending 与仓库 API 快照，分钟级差异可能造成少量偏差。
4. **Fork 较上期**：只对连续上榜且上期存在同口径快照的项目计算；新上榜项目标为“缺失”。
5. **工程活跃度**：统计 2026-10-08 00:00 UTC 起约 7 天默认分支提交；单仓库最多读取 100 条，达到上限记为 `≥100`。
6. **作者身份**：优先按提交关联的 GitHub 登录名去重，缺失时使用提交作者邮箱或名称；机器人、合并提交和共同作者会造成偏差，不等同于完整贡献者人数。
7. **讨论热度**：统计同一窗口新建 Issue，使用 `is:issue` 排除 PR；自动化工单、路线图拆分和模板化提交可能放大数量。
8. **开源范围**：主榜要求存在可验证的标准开源许可。`VoiceStudio` 为 AGPL-3.0；网络服务分发修改版时需要履行相应源码义务。
9. **爆发原因**：依据 README、许可证、近期提交、Issue 与榜单表现作分析推断，不代表维护者官方结论。

## 项目分析

### 1. morluto/rea

- **主要用途**：通过统一 MCP/CLI 对网站、JavaScript/Electron 应用、.NET 程序、APK、固件、数据库与原生二进制进行证据化逆向分析。
- **技术栈**：TypeScript、Node.js 22+、MCP、Hopper/Ghidra/IDA、JADX、Binwalk/Unblob；MIT。
- **近期增长及口径**：约 **+41,034 Star/24h、+214,837 Star/7d**，相对日增约 **20.5%**。当前 241,124 Star、59,983 Fork，Fork 较上期约 +9,743；连续第一。
- **贡献与讨论**：近 7 天提交 **≥100**、约 11 个作者身份、1,087 个新 Issue；最新修复 Android 长版本号、IDA 超时预算和缺少来源限制语义的缓存快照。
- **爆发原因**：它把浏览器行为、反编译器、固件与原生二进制统一为 Agent 可调用的证据链，覆盖面和修复速度持续扩张；同时“逆向任何东西”的叙事形成了强社交传播。
- **亮点**：结果不仅给结论，还附带证据、覆盖状态和未知项；近期改动继续减少“缺失数据被误报为完整结论”的风险。
- **潜在风险**：明显双重用途，只能分析获授权目标。安装脚本、浏览器捕获、反编译器和 MCP 权限会扩大供应链、隐私与主机安全面；1,087 个新 Issue 显示治理压力巨大，异常涨星也需与活跃用户和实际部署分开判断。
- **适合人群与关注程度**：获授权的软件审计、兼容性研究、恶意样本隔离分析和企业逆向 Agent 团队；**★★★★★**。

- **亮点**：模型管理、配音时间轴、批量任务、监控文件夹、recipe 和 MCP 形成完整工作站，而不是单一推理脚本。
