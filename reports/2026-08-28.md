## 统计口径与限制

1. **24 小时新增 Star**：采用 GitHub Trending 日榜的 “stars today”。它是滚动窗口指标，抓取时间差会导致其与 API 累计 Star 无法简单相加校验。
2. **7 天新增 Star**：优先采用 GitHub Trending 周榜的 “stars this week”。本期前十只有 `awesome-gpt-image-2` 出现在周榜公开结果中；其余项目标记为“缺失”，不以累计 Star 反推。
3. **Fork 变化**：仅对上一期已有 API 快照且本期继续上榜的项目计算两次快照差；新上榜项目不伪造 24 小时 Fork 增量。
4. **提交与贡献者**：统计 2026-08-21 00:00 UTC 起约 7 天内 GitHub Commits API 数据；最多读取 100 条。独立作者按 GitHub 登录名或提交标识去重，是近似值。
5. **Issue/PR 活跃度**：统计同一窗口内新建的 Issue 和 PR。它反映讨论与协作流量，不代表问题已经解决或代码已经合并。
6. **Discussions**：GitHub 缺少便于跨仓库统一比较的公开增量口径，本报告使用 Issue/PR、新增 Fork、榜单连续性和社区入口作为代理；无法可靠量化时标为缺失。
7. **爆发原因**：根据 README、近期活动和榜单位置作出的分析判断，不代表维护者官方结论。

## 项目分析

### 1. tt-a1i/archify

- **主要用途**：让 Agent 把代码库或系统描述转为可交互、可验证的架构图、工作流图、时序图、数据流图和生命周期图。
- **技术栈**：JavaScript、Node.js CLI、typed JSON IR、自包含 HTML/SVG、Agent Skill；MIT License。
- **近期增长**：日榜约 **+4,260 Star**；周榜公开结果缺失；相对日增约 **22.6%**。API 当前 23,105 Star、1,490 Fork；较昨日 Fork 约 **+250**。
- **活跃度与口径**：近 7 天 31 次提交、约 5 名独立作者、17 个新 Issue、34 个新 PR，增长同时得到代码与社区活动支撑。
- **爆发原因**：类型化中间表示、确定性校验、Last-good 预览、源码修订证据和 Before/Delta/After 对比，直接解决 Agent 架构图“好看但不可信”的痛点。
- **亮点**：机器可读修复凭据；可导出 HTML、PNG、SVG、WebM；能够把架构变化转成可审查交付物，而非一次性图片。
- **潜在风险**：校验的是已建模事实，不是线上运行时真相；动态依赖仍可能漏检；内部拓扑、路径和信任边界在分享前必须脱敏。
- **适合人群**：架构师、代码审查与研发效能团队、需要图像辅助理解复杂系统的学习者。
- **值得关注程度**：**★★★★★**。对代码审查系统中的架构 Delta、证据链和合并请求可视化有直接借鉴价值。

## 最值得深入研究的 3 个项目

### 1. tt-a1i/archify

**理由**：连续两天增长并冲到第一，且提交、PR 与 Fork 同步上升。它的真正价值是把架构图变成“类型化事实 + 校验器 + Git 证据 + 可交付视图”，可直接迁移到代码审查系统的架构变化审查。

**建议验证**：真实 Java/Python 多模块仓库的依赖召回率；与 Git diff 的一致性；动态调用和配置依赖的漏检率；敏感拓扑脱敏；将验证凭据和 Delta 图写入 GitLab MR 评论的实现成本。

### 2. calesthio/OpenMontage

**理由**：它展示了较完整的 Agent 生产架构：先选管线，再建立提案和成本预算，经过人工审批生成素材，最后执行技术自检。这个结构不仅适用于视频，也能借鉴到游戏资产生成、代码审查和文档生产。

**建议验证**：主流 NVIDIA/AMD GPU 上 Wan 2.1/2.2 本地视频路径的实际兼容性；ComfyUI 是否能替代部分供应商；参考视频分析的版权边界；API Key 隔离；失败重试是否重复收费；审批记录和素材来源能否完整追溯。

### 3. K-Dense-AI/scientific-agent-skills

**理由**：它把“领域知识”从模型记忆迁移到可安装、可锁版本、要求引用上游来源的 Skills 集合，对 Agent、RAG 和幻觉治理研究非常契合。它适合用来观察怎样让 Agent 知道何时查数据库、怎样调用工具、怎样留下引用。

**建议验证**：随机抽取 10 个 Skills 检查来源、版本、输入输出约束和失败处理；医学类结果是否强制证据与不确定性声明；数据库失效时是否安全失败；Skill 指令与真实 API 是否同步；能否复用其结构设计内部代码审查 Skills。
