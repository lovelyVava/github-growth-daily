## 项目分析

### 1. NVIDIA/auto-ontology

- **主要用途**：从企业数据库和元数据构建语义本体/知识图谱，为 Agent 提供可信指标定义、关系、血缘、SQL 校验与来源证据。
- **技术栈**：Python、FastAPI、Postgres、Next.js/React、MCP/CLI/API、数据库连接器与 NVIDIA NIM；Apache-2.0。
- **近期增长及口径**：约 **+2,679 Star/24h**，相对日增约 52%；7 天直接值缺失，最近 2 天总 Star 快照差约 +3,210。当前 7,871 Star、634 Fork。
- **贡献与讨论**：近 7 天约 18 次提交、作者身份缺失、14 个新 Issue。最新版本固定 Python 3.12.16；近期讨论包括托管 NVIDIA API 的结构化输出兼容、RLS/CLS、连接器数据正确性和新增数据源。
- **爆发原因**：Agent 数据分析的瓶颈正在从“能否生成 SQL”转向“指标含义是否一致、查询是否可验证”；NVIDIA 品牌、MCP 接口和 1.2.0 版本共同放大传播。
- **亮点**：把语义、关系、认证、数据连接与查询验证放到同一控制层，并强调答案血缘而非只返回自然语言。
- **潜在风险**：错误本体或连接器错误会以“可信上下文”形式放大；项目暂不接收外部贡献，生态修复路径受限。生产环境还需独立验证只读权限、行列级安全、查询成本和提示注入边界。
- **适合人群与关注程度**：企业数据平台、语义层、Text-to-SQL、RAG/Agent 治理团队；**★★★★★**。

### 2. vercel-labs/agent-desktop

- **主要用途**：让 AI Agent 通过操作系统无障碍树读取并操作 macOS、Windows、Linux 桌面应用，不依赖像素匹配。
- **技术栈**：Rust 原生核心、C 库、npm CLI、macOS Accessibility、Windows UI Automation、Linux AT-SPI；Apache-2.0。
- **近期增长及口径**：约 **+2,173 Star/24h**、相对日增约 14%；历史仅覆盖 4 天，期间快照差约 +8,070。当前 17,317 Star、1,233 Fork。
- **贡献与讨论**：近 7 天约 34 次提交、70 个新 Issue；最新在 macOS 用 `libproc` 读取进程清单。问题集中在 WPF 控件状态、容器/命名空间驱动桌面会话和退出确认弹窗。
- **爆发原因**：电脑操作 Agent 正从截图坐标走向结构化 UI 树，令动作更省 token、可验证且更容易跨分辨率复现；跨三大桌面平台扩大了受众。
- **亮点**：每次动作后可重新读取树验证结果，CLI 与模型解耦，适合做确定性执行层和多模型评测。
- **潜在风险**：无障碍权限接近“全桌面控制”；快照、剪贴板、截图、命令输出可能包含隐私和凭据。跨平台语义仍不一致，70 个新 Issue 表明兼容矩阵处于快速扩张期。
- **适合人群与关注程度**：Computer Use Agent、桌面自动化、无障碍测试和企业 RPA 团队；**★★★★★**。
