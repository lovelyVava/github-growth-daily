## 项目分析

### 1. elementalsouls/Claude-BugHunter

- **主要用途**：为 Claude Code 提供漏洞挖掘与外部红队 Skill 包，覆盖漏洞模式、侦察、验证、报告及企业身份/基础设施攻击矩阵。
- **技术栈**：Python、Shell/PowerShell、Claude Code Skills、命令行引擎和报告模板；MIT。
- **近期增长及口径**：约 **+1,644 Star/24h**、相对日增约 7.8%；当前 22,702 Star、2,331 Fork。日增较上一期 +2,029 回落约 19.0%，但仍断层领先。
- **贡献与讨论**：近七日约 27 次提交、16 个新议题；最新加入基于侦察快照差异的回归漏洞发现，并修复 URL authority 反斜杠造成的 Scope 绕过和凭据脱敏缺口。
- **爆发原因（推断）**：把已披露漏洞知识与工作流包装成可调用技能，能快速构建侦察、验证和报告链路。
- **亮点**：传播热度持续，更新开始强化确定性 Diff、Scope 门禁和证据卫生，而不只是扩充提示词。
- **潜在风险**：只能用于明确授权范围；范围误判、敏感数据泄漏、误报和攻击性命令误用都可能造成真实伤害。
- **适合人群与关注程度**：经授权的渗透测试、Bug Bounty、AppSec 和红队研究人员；**★★★★☆**。

### 2. mvanhorn/last30days-skill

- **主要用途**：聚合 Reddit、X、YouTube、Hacker News、Polymarket 与 Web 的近期内容，生成带来源和互动信号的研究摘要。
- **技术栈**：Python、站点/API 搜索、浏览器 Cookie、转录抓取、SearXNG、Agent Skill 与多宿主适配；MIT。
- **近期增长及口径**：约 **+950 Star/24h、+5,369 Star/7d**；当前 74,966 Star、6,604 Fork。日增较上一期加速约 19.2%，周增小幅回落 1.5%。
- **贡献与讨论**：近七日约 72 次提交、12 个新议题；最新改进 Watchlist 的首次出现告警。
- **爆发原因（推断）**：通用搜索对近期社区信号覆盖不足，而产品口碑、热点与市场情绪需要跨平台、带时间约束的检索。
- **亮点**：日周双窗口和提交量同时保持高位；多源研究、Watchlist、回退和安全边界形成完整产品闭环。
- **潜在风险**：受站点条款、Cookie、API 配额及反爬影响；社交信号可被操纵，隐私、SSRF 和事实核验必须独立治理。
- **适合人群与关注程度**：市场研究、产品调研、开发者关系、内容策略和 OSINT 工具团队；**★★★★★**。

### 3. HKUDS/CLI-Anything

- **主要用途**：把带 GUI 或复杂交互的软件自动包装为结构化 CLI，使编码 Agent 能稳定调用现有应用能力。
- **技术栈**：Python、应用探测、CLI 生成、命令契约、测试与 Agent 集成；Apache-2.0。
- **近期增长及口径**：约 **+1,094 Star/24h**、相对日增约 1.7%；当前 65,552 Star、5,956 Fork。七天直接增量缺失。
- **贡献与讨论**：近七日默认分支提交为 **0**、新议题 17 个；这说明当前涨星主要来自传播或既有功能曝光，而非本周代码迭代。
- **爆发原因（推断）**：大量成熟软件缺少 Agent 友好的稳定接口，把 GUI 能力映射到可测试 CLI 正好补齐执行层缺口。
- **亮点**：目标明确，能复用既有软件生态，而无需每个 Agent 团队重新开发 API。
- **潜在风险**：自动生成的 CLI 可能无法覆盖 GUI 状态、权限和异步错误；零周提交削弱持续增长判断，需验证最新版本和维护节奏。
- **适合人群与关注程度**：桌面自动化、Agent 工具链、CLI 设计和应用集成研究者；**★★★☆☆**。

### 4. XiaoYouChR/Ghost-Downloader-3

- **主要用途**：跨平台多协议下载管理器，覆盖 HTTP、BT、视频提取、浏览器扩展、任务恢复和代理设置。
- **技术栈**：Python、PySide/Qt、aria2/BT、yt-dlp、Nuitka、浏览器扩展及多平台发布链；GPL-3.0。
- **近期增长及口径**：约 **+950 Star/24h**、相对日增约 5.5%；当前 18,116 Star、1,078 Fork。日增较上一期回落约 12.6%，但绝对增量仍高。
- **贡献与讨论**：近七日约 66 次提交、60 个新议题；最新修复功能包更新弹窗的国际化提取。
- **爆发原因（推断）**：一体化下载、中文用户基础、跨平台发行和视频/BT 支持形成大众传播效应。
- **亮点**：日增、提交、讨论三类信号同时成立，且提交量较上一期继续上升。
- **潜在风险**：自更新、代理、浏览器扩展和外置存储扩大攻击面；BT/视频下载可能涉及版权与站点条款，GPL 分发义务也需遵守。
- **适合人群与关注程度**：跨平台下载管理用户、桌面应用和下载协议开发者；**★★★★☆**。

### 5. google-labs-code/stitch-skills

- **主要用途**：为 Stitch MCP 提供符合 Agent Skills 开放标准的技能库，支持设计提取、页面生成与前端工作流。
- **技术栈**：TypeScript、MCP、Agent Skills、设计稿/网页提取和多编码 Agent 适配；Apache-2.0。
- **近期增长及口径**：约 **+352 Star/24h、+2,626 Star/7d**，相对日增约 2.8%、相对周增约 26%；当前 12,922 Star、1,535 Fork。
- **贡献与讨论**：近七日约 20 次提交、1 个新议题；最新合并从实时 URL 提取设计 Markdown 的能力。
- **爆发原因（推断）**：用户希望将设计工具能力以标准 Skill 形式复用到 Gemini CLI、Claude Code、Cursor 等多个宿主，而非绑定单一 Agent。
- **亮点**：日周双窗口同时成立，Skill 标准、MCP 和设计到代码场景组合清晰。
- **潜在风险**：议题量很低，真实生产反馈仍有限；依赖 Stitch 服务与宿主实现，认证、配额和生成结果一致性需独立验证。
- **适合人群与关注程度**：设计工程、前端生成、MCP/Skill 标准和多 Agent 平台团队；**★★★★☆**。

### 6. kajisho5/ffmpeg-skill

- **主要用途**：为 Claude Code、Cursor、Codex 等 Agent 提供本地视频剪辑、字幕、画幅、响度和平台导出工具。
- **技术栈**：Python、FFmpeg/FFprobe、Whisper、MCP Server、机器可读工具契约和 npm 安装入口；MIT。
- **近期增长及口径**：24 小时直接值缺失；约 **+2,993 Star/7d**、相对周增约 38%。当前约 10.8k Star、924 Fork；周增较上一期回落约 23.1%。
- **贡献与讨论**：近七日提交 **≥100**、41 个新议题；最新加入 Agent 插件市场和 Codex 插件入口。
- **爆发原因（推断）**：把复杂 FFmpeg 参数变成可发现、可组合、可验证的本地 Tool Contract，补齐视频 Agent 执行层。
- **亮点**：无需云 API Key，覆盖探测、编辑和交付，并用 FFprobe/回归样本验证输出。
- **潜在风险**：接口快速变化；HDR、VFR、响度、GPU 路径、本地文件权限和第三方媒体版权都需隔离验证。
- **适合人群与关注程度**：短视频自动化、媒体流水线、字幕音频处理及 MCP/Agent Tool 开发者；**★★★★★**。

### 7. GoogleChrome/modern-web-guidance-src

- **主要用途**：把现代 Web 平台能力、最佳实践和兼容性数据变成编码 Agent 可检索、可评测的技能，减少陈旧前端模式。
- **技术栈**：TypeScript/Node.js 22+、CLI 安装器、知识指南、Legacy Scanner、评测和覆盖率面板；Apache-2.0。
- **近期增长及口径**：24 小时直接值缺失；约 **+2,494 Star/7d**、相对周增约 30%。当前约 10.9k Star、826 Fork，周增较上一期回落约 7.4%。
- **贡献与讨论**：近七日约 42 次提交、21 个新议题；最新触发公开 Harness 的 Pages 部署，并继续完善评测基础设施。
- **爆发原因（推断）**：LLM 训练语料含大量遗留 Web 写法，而浏览器平台已提供更原生、性能更好且无障碍更清晰的替代方案。
- **亮点**：由浏览器与 Web 社区共同维护，并把规则、扫描和评测结合，适合做可治理的 Agent 知识更新层。
- **潜在风险**：规则可能领先企业浏览器基线；框架特有语法和草案特性可能导致误报，不能直接批量改写生产代码。
- **适合人群与关注程度**：前端平台、Web 标准、浏览器兼容、无障碍及编码 Agent 评测团队；**★★★★★**。

- **技术栈**：TypeScript/Node.js、爬虫与浏览器、队列、PDF/HTML 转 Markdown、REST API、SDK 和自托管组件；AGPL-3.0。

## 当天技术趋势

1. **Agent 工具接口正在标准化**：`CLI-Anything` 试图把现有软件变成结构化 CLI，`Stitch Skills` 则以 Agent Skills + MCP 跨宿主分发；竞争焦点从“能不能调用”转向“接口是否稳定、可测试、可移植”。
2. **近期情报仍是最强持续增长场景**：`last30days-skill` 日周双增且有 72 次提交，说明“新鲜、多源、带互动信号”的检索能力仍是通用 Agent 的缺口。

4. **企业 Agent 门禁更关注失败语义**：`Open Code Review` 的增长与讨论围绕搜索、排除、上下文和 CI 可靠性，确定性保护层的重要性超过单纯换更强模型。
5. **高 Star 不等于当周活跃**：`CLI-Anything` 的 1,094 日增与零周提交形成鲜明对比；本期将其列为高增长观察项，而非高成熟度推荐。
