## 项目分析

### 1. sherlock-project/sherlock

- **主要用途**：按用户名在大量社交网站中检索同名账户，用于授权 OSINT、数字足迹调查与威胁情报侦察。
- **技术栈**：Python CLI、异步 HTTP、数据驱动的网站规则、PyPI/Docker；MIT。
- **近期增长及口径**：约 **+2,373 Star/24h**；七日值缺失，最近 2 天快照差约 +3,677。当前 104,801 Star、12,216 Fork，Fork +263，由第三升至第一。
- **贡献与讨论**：近 7 天零提交、8 个新 Issue；问题涉及小红书/抖音人工检查、误报/漏报和站点支持请求。
- **爆发原因（推断）**：成熟 OSINT 工具被再度集中传播，用户名跨站查询的演示效果直观，安全与隐私话题放大了受众。
- **亮点**：安装和使用门槛低、站点覆盖广、结果可导出，适合快速建立调查线索。
- **潜在风险**：同名账户不等于同一自然人；站点页面变化会造成误报，且使用涉及隐私、骚扰、站点条款和司法辖区限制。零提交说明本轮主要是传播增长。
- **适合人群与关注程度**：授权 OSINT、品牌保护、威胁情报和数字取证团队；**★★★★☆**。

### 2. milind-soni/OpenMausBot

- **主要用途**：自托管多 Bot 聊天应用，让 AI Bot 在隔离虚拟机中使用浏览器、终端和文件工具完成任务。
- **技术栈**：TypeScript、Electron、Expo、Node.js、Docker/虚拟机与计算机操作 Agent；Apache-2.0。
- **近期增长及口径**：约 **+1,439 Star/24h、+7,621 Star/7d**。当前 18,777 Star、2,588 Fork，Fork +148，连续第二。
- **贡献与讨论**：近 7 天提交与新 Issue 均 **≥100**。最新修复 MCP 登录提示、内存锁定告警和任务接力；新问题包括实时音频、MCP 超时和第二台电脑无法连接宿主。
- **爆发原因（推断）**：把多 Agent 对话、桌面/移动端和可操作电脑的 VM 结合，可运行产品比单一 Skill 更容易形成持续传播。
- **亮点**：包含真实执行环境、任务交接和多端产品形态，不只是提示词或演示仓库。
- **潜在风险**：代码与工单同时触顶意味着工程推进快但稳定性压力大；终端、浏览器、文件和网络权限必须在 VM 层隔离，不能把生产凭据和宿主目录直接暴露给 Bot。
- **适合人群与关注程度**：自托管 Agent、桌面 AI、虚拟化和多 Agent 产品团队；**★★★★☆**。

### 3. NVIDIA/auto-ontology

- **主要用途**：从企业元数据构建语义本体和关系图，为 Agent 提供指标定义、SQL 校验、血缘和来源证据。
- **技术栈**：Python、FastAPI、Postgres、Next.js/React、MCP/CLI/API、数据库连接器与 NVIDIA NIM；Apache-2.0。
- **近期增长及口径**：周榜约 **+9,327 Star/7d**，相邻日快照差约 +322。当前 10,601 Star、867 Fork，Fork +61，由第四升至第三。
- **贡献与讨论**：近 7 天约 17 次提交、37 个新 Issue；最新固定 Python 3.12.16 并发布 1.2.0。工单涉及 Oracle 存储集成、人工审批输出、CSV/Excel 编码和图表排序。
- **爆发原因（推断）**：企业 Agent 的竞争点从“能否查询”转向“语义是否一致、结论是否可验证”，本体、血缘与审批成为新的数据控制面。
- **亮点**：把语义、关系、连接器、查询和答案证据链放在同一层，并以 MCP 暴露给 Agent。
- **潜在风险**：错误本体或连接器结果会被放大为“可信上下文”；生产使用必须验证只读权限、RLS/CLS、查询成本、人工审批、提示注入和审计日志。
- **适合人群与关注程度**：企业数据平台、语义层、Text-to-SQL、RAG 与 Agent 治理团队；**★★★★★**。

### 4. meta/astryx

- **主要用途**：Meta 内部成长八年的开源设计系统，为人类开发者和编码 Agent 提供一致的组件、主题、模板、文档和 CLI。
- **技术栈**：React 19、TypeScript、StyleX、CSS 自定义属性、Storybook、pnpm Monorepo；MIT，当前 Beta。

- **适合人群与关注程度**：设计系统、前端平台、React、可访问性和 Agent UI 生成团队；**★★★★★**。

### 5. vercel-labs/agent-browser

- **主要用途**：让 AI Agent 通过命令行打开网页、读取可访问性树快照，并以稳定元素引用执行点击、输入、下载和录制。
- **技术栈**：Rust 原生 CLI、Chrome DevTools Protocol、Node/npm 包装、后台 daemon、MCP/Skills；Apache-2.0。
- **近期增长及口径**：约 **+815 Star/24h、+2,190 Star/7d**。当前 47,898 Star、3,272 Fork，新上榜第五。
- **贡献与讨论**：近 7 天约 39 次提交、20 个新 Issue；最新准备 v0.42.0 并加入 flow 重放。问题涉及 Chrome 157 标志失效、Windows 对话框卡死和键盘事件时序。
- **爆发原因（推断）**：浏览器操作正在从重型 SDK 转向 Agent 友好的短命令、文本快照和可恢复会话；Vercel Labs 品牌与跨平台原生二进制促进采用。
- **亮点**：可访问性树输出紧凑、元素引用适合模型使用，并提供会话、录制、调试、权限和多浏览器提供商支持。
- **潜在风险**：浏览器会接触 Cookie、密码、下载文件和第三方内容；网页提示注入、过期元素引用、域名跳转和危险操作必须由 allowlist、确认策略和隔离 profile 控制。
- **适合人群与关注程度**：浏览器 Agent、自动化测试、研究采集和沙箱平台团队；**★★★★★**。

### 6. thedotmack/claude-mem

- **主要用途**：为 Claude Code、Codex、Cursor、OpenCode 等编码 Agent 持久记录会话观察，在下一次工作时按需检索和注入上下文。
- **技术栈**：TypeScript、Bun worker、SQLite/FTS5、Chroma 向量检索、生命周期 Hooks、MCP 与本地 Web Viewer；Apache-2.0。
- **近期增长及口径**：周榜约 **+6,443 Star/7d**，相邻日快照差约 +195。当前 115,040 Star、9,996 Fork，新上榜第六。
- **贡献与讨论**：近 7 天提交 **≥100**、53 个新 Issue；最新优化历史会话读取并修复安装器。问题涉及语言错误、缺少 `node_modules` 时 Bun/Sharp 死锁和付费试用提示。
- **爆发原因（推断）**：长期任务的核心瓶颈正从模型上下文长度转向“记住什么、何时召回、如何追溯”，跨多种编码 Agent 的统一记忆层具有强需求。
- **亮点**：本地 SQLite 为主、支持混合检索、观察可引用，并把记忆采集、搜索和会话注入连成完整链路。
- **潜在风险**：工具调用、截图和项目历史可能包含密钥或个人信息；匿名遥测默认开启，云同步虽为可选但需明确审查。错误或被污染的记忆会在后续会话持续放大。
- **适合人群与关注程度**：长周期编码 Agent、知识工作、上下文工程和本地记忆系统团队；**★★★★★**。

### 7. D4Vinci/Scrapling

- **近期增长及口径**：周榜约 **+8,342 Star/7d**，相邻日快照差约 +274。当前 100,076 Star、10,456 Fork，Fork +46，保持第七。

### 8. jub0t/Concat

- **主要用途**：本地优先的跨平台视频编辑器，提供剪辑、字幕、TTS/声音克隆、抠像、特效、4K 导出，并允许 Agent 通过 MCP/JSON-RPC 操作。
- **技术栈**：Rust 原生引擎、GPU 合成、FFmpeg、Whisper、本地 AI 模型、MCP/JSON-RPC/gRPC；AGPL-3.0-or-later，闭源使用另有商业许可。

## 当天技术趋势

1. **Agent 的基础设施继续拆成可组合控制面。** `Auto Ontology` 负责数据语义，`claude-mem` 负责长期记忆，`agent-browser` 负责网页操作，`Worktrunk` 负责代码工作区；单一“大 Agent”正在被更可审计的专用层替代。
2. **本地 AI 从开发工具延伸到创作与集群平台。** `Concat` 把字幕、声音和视频处理留在本地；`NVKE` 把 GPU Kubernetes 集群包装成内部托管服务。二者都以隐私或基础设施主权换取更高运维复杂度。
3. **设计系统开始显式服务编码 Agent。** `Astryx` 不只发布组件，也把文档、CLI、模板和可预测 API 作为人机共用界面；“Agent 可读性”正成为设计系统的新质量维度。
4. **增长质量分化明显。** `OpenMausBot`、`Astryx`、`claude-mem`、`Concat` 同时拥有强增长和提交触顶；`Sherlock` 则是高 Star/Fork 增长、零提交，更多反映再传播而非本周工程推进。
5. **安全边界比功能演示更重要。** 浏览器 Profile、Agent 记忆、GPU 管理平面、OSINT 结果和本地媒体模型都接触敏感数据。域名 allowlist、最小权限、隔离环境、数据保留策略和许可证评估应在试用前完成。
