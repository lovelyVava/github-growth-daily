## 项目分析

### 1. cloudflare/security-audit-skill

- **主要用途**：把编码 Agent 组织成多阶段安全审计流程，覆盖侦察、覆盖率驱动挖掘、独立验证、结构化发现和最终报告。
- **技术栈**：JavaScript/Node.js、Markdown Skill、JSON Schema、coverage ledger、独立子 Agent 验证与零依赖校验脚本；MIT。
- **近期增长及口径**：约 **+2,979 Star/24h**，相对日增约 **8.0%**；7 天直接值缺失。当前 40,164 Star、2,507 Fork，Fork 快照较上期 +169；由第二升至第一。
- **贡献与讨论**：近 7 天默认分支 0 次提交、作者身份缺失、5 个新 Issue；最新问题指出目标仓库名可影响输出路径及历史运行复用，可能形成路径逃逸和跨目标污染。
- **爆发原因**：独立验证、覆盖账本与机器可校验 findings 直击 Agent 安全审计可信度；Cloudflare 品牌和可安装 Skill 形态放大传播。
- **亮点**：明确区分 confirmed、needs_validation、rejected，以覆盖账本减少盲区，并要求最终记录再经独立 Agent 核验。
- **潜在风险**：最新路径问题涉及审计结果完整性和隔离边界；没有 OS 级沙箱时也不能安全执行目标代码。涨星和 Fork 强劲但近周零提交，不能把传播速度当作修复速度。
- **适合人群与关注程度**：AppSec、代码审查平台、Agent 安全评测和漏洞研究流程设计者；**★★★★☆**。

### 3. Graphify-Labs/graphify

- **主要用途**：把代码、文档、SQL schema、配置和 PDF 构造成可查询知识图谱，让 Agent 通过节点、路径和解释接口理解大型代码库。
- **技术栈**：Python 3.10+、tree-sitter AST、Leiden 社区发现、HTML/JSON 图输出与 Agent Skill；Apache-2.0。
- **近期增长及口径**：约 **+1,408 Star/24h**，相对日增约 **1.1%**；7 天直接值缺失。当前 133,316 Star、12,740 Fork，Fork 快照较上期 +77；由第四升至第三。
- **贡献与讨论**：近 7 天提交 **≥99**、作者身份缺失、58 个新 Issue；最新更新安全威胁面表，近期问题涉及 VB.NET `Imports` 节点缺少 `source_file` 等跨语言建模边界。
- **爆发原因**：编码 Agent 对持久、可解释代码结构的需求上升；本地确定性 AST、显式/推断边标记和无向量库设计，与通用 RAG 形成清晰区分。
- **亮点**：每条边标记 `EXTRACTED` 或 `INFERRED`，支持 path/query/explain；代码解析本地完成，图可持久化为开放 JSON。
- **潜在风险**：推断边仍可能错误，跨语言动态调用、SQL 名称解析和低代码/XML 关系需实测；云版持续同步与连接器能力不等同于本地开源版本。
- **适合人群与关注程度**：代码知识库、跨微服务依赖图、Agent 代码理解和架构审计团队；**★★★★★**。
