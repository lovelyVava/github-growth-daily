## 数据口径与限制

1. **24 小时新增 Star**：优先采用 GitHub Trending 日榜的 `stars today`，属于滚动窗口近似值。
2. **相邻快照估算**：`diagram-design` 今天未出现在日榜可见条目中，其 24 小时值用 8 月 16 日报告累计 Star 快照 18,503 与今天仓库 API 快照 19,502 的差值估算为 999；窗口并非秒级对齐。
3. **7 天新增 Star**：采用周榜的 `stars this week`。未进入周榜可见范围时标记“缺失”；相邻两期日增之和仅作近两日下限。
4. **Fork**：表中为观察时累计快照。GitHub Trending 不统一提供 24h/7d Fork 增量，故 **Fork 增量统一标记缺失**。
5. **贡献者与讨论热度**：过去 7 天提交数、新建 Issue/PR 数来自 GitHub API 查询；提交返回 100 条时记为“≥100”。Discussions 只记录是否启用，无法取得同口径的 7 天讨论增量。
6. **排名补充规则**：日榜可见项目优先按日增排序；周榜补充项排在其后，避免将周增量或日均值伪装成精确日增。
7. 累计 Star/Fork 会持续变化，仓库 API 与 Trending 页面可能有数分钟时间差。

## 当天技术趋势

1. **Agent 从“会做事”转向“能长期、安全、可解释地做事”**：`prime-agent` 关注持续运行与自改进，`semantica` 关注上下文图谱与决策溯源，热点正向可靠性和治理层上移。
2. **小模型与端侧 Agent 继续升温**：`needle` 把工具调用、置信度和有界内存做进极小模型；它代表的不只是模型压缩，而是为设备任务重新设计能力边界。
3. **Agent Skill 正在产品化**：`diagram-design` 的高周增表明，可安装、带资产与审美约束的技能包比零散提示词更容易传播和复用。

5. **“开源替代品”开始叠加可编程接口**：`OpenCut` 不只定位视频编辑器，还规划 MCP、插件和无头渲染；创作者工具正在向 Agent 可调用基础设施演化。
