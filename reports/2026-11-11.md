8. **综合排序**：综合 24h/7d Star、相对增速、Fork、提交、讨论质量、许可和部署风险；不是 GitHub Trending 原始顺序，也不按累计 Star 排名。
9. **开源范围**：主榜要求存在可验证的标准开源许可。没有明确仓库级许可证或限制商业使用的项目不进入严格开源主榜。

## 项目分析

### 1. sherlock-project/sherlock

- **主要用途**：按用户名在大量社交网站检索同名账户，用于授权 OSINT、数字足迹调查和威胁情报侦察。
- **技术栈**：Python CLI、异步 HTTP、数据驱动的网站规则、PyPI/Docker；MIT。
- **近期增长及口径**：约 **+4,267 Star/24h**；可靠七日直接值缺失，最近 4 天快照差约 +9,414。当前 107,740 Star、12,459 Fork，Fork +243，连续第一。
- **贡献与讨论**：近 7 天零提交、11 个新 Issue；集中在站点支持、Houzz 误报和用户名漏报。
- **爆发原因（推断）**：成熟 OSINT 工具继续被安全社区集中传播，跨站用户名查询的演示效果直观；Fork 增长也显示大量用户在实际试用或定制。
- **亮点**：安装简单、站点覆盖广、结果可导出，适合快速建立调查线索。
- **潜在风险**：同名账户不等于同一自然人；站点变化会产生误报，且使用涉及隐私、骚扰、服务条款和司法辖区限制。零提交说明本轮仍主要是传播增长。
- **适合人群与关注程度**：授权 OSINT、品牌保护、威胁情报和数字取证团队；**★★★★☆**。

### 2. meta/astryx

- **主要用途**：Meta 内部成长八年的开源设计系统，为开发者和编码 Agent 提供组件、主题、模板、文档和 CLI。
- **技术栈**：React 19、TypeScript、StyleX、CSS 自定义属性、Storybook、pnpm Monorepo；MIT，当前 Beta。
- **近期增长及口径**：约 **+3,278 Star/24h**，最近 4 天快照差约 +6,806。当前 20,854 Star、1,583 Fork，Fork +198，由第四升至第二。
- **贡献与讨论**：近 7 天提交 **≥100**、34 个新 Issue；最新加入 Layer 侧向入场动画并继续组件审计。讨论涉及搜索无结果交互、TextArea 长度限制、评分组件和中文文档。
- **爆发原因（推断）**：Meta 将支撑 13,000+ 应用、150+ 组件的内部体系公开，并把“人和 Agent 使用同一套 API/文档”作为核心卖点，品牌、规模和 Agent 叙事叠加。
- **亮点**：组件、主题、模板、CLI、文档和可访问性测试形成完整系统；消费者无需接入 StyleX 构建插件即可使用预编译 CSS。
- **潜在风险**：仍处 Beta 且要求 React 19；提交触顶与大量 RFC 表明接口仍快速变化。迁移前需评估升级策略、包体积、主题覆盖、国际化和无障碍基线。
- **适合人群与关注程度**：设计系统、前端平台、React、可访问性和 Agent UI 生成团队；**★★★★★**。

### 3. milind-soni/OpenMausBot

- **主要用途**：自托管多 Bot 聊天应用，让 AI Bot 在隔离虚拟机中使用浏览器、终端和文件工具完成任务。
- **技术栈**：TypeScript、Electron、Expo、Node.js、Docker/虚拟机与计算机操作 Agent；Apache-2.0。
- **近期增长及口径**：约 **+1,587 Star/24h、+8,325 Star/7d**。当前 20,074 Star、2,744 Fork，Fork +156，由第二降至第三。
- **贡献与讨论**：近 7 天提交与新 Issue 均 **≥100**。最新修复沙箱 scope 和自托管隧道；问题包括桌面互联、移动端路由和 Pi 引擎没有 MCP 工具。
- **爆发原因（推断）**：把多 Agent 对话、桌面/移动端和可操作电脑的 VM 组合成完整产品，比单一 Skill 更容易维持传播。
- **亮点**：包含真实执行环境、任务接力、连接器和多端产品，不只是提示词或概念演示。
- **潜在风险**：代码与工单同时触顶意味着迭代快但稳定性压力大；终端、浏览器、文件、网络和第三方连接器必须在 VM 层隔离，不能直接暴露生产凭据。
- **适合人群与关注程度**：自托管 Agent、桌面 AI、虚拟化和多 Agent 产品团队；**★★★★☆**。

### 4. NVIDIA/auto-ontology

- **主要用途**：从企业元数据构建语义本体和关系图，为 Agent 提供指标定义、SQL 校验、血缘和来源证据。
- **技术栈**：Python、FastAPI、Postgres、Next.js/React、MCP/CLI/API、数据库连接器与 NVIDIA NIM；Apache-2.0。
- **近期增长及口径**：周榜约 **+10,159 Star/7d**，相邻日快照差约 +179。当前 11,156 Star、913 Fork，Fork +46，由第三降至第四。
- **贡献与讨论**：近 7 天约 14 次提交、38 个新 Issue；最新加入行为准则并固定 Python 3.12.16。工单涉及计数问题误路由、SQL 校验丢表、Oracle 集成和人工审批。
- **爆发原因（推断）**：企业 Agent 的竞争点从“能否查询”转向“语义是否一致、结论是否可验证”，本体、血缘和审批成为新的数据控制面。
- **亮点**：把语义、关系、连接器、查询和答案证据链放在同一层，并以 MCP 暴露给 Agent。
- **潜在风险**：错误本体或连接器结果会被放大为可信上下文；计数与 SQL 校验问题说明尚需严格回归。生产使用必须验证只读权限、RLS/CLS、人工审批和审计日志。
- **适合人群与关注程度**：企业数据平台、语义层、Text-to-SQL、RAG 与 Agent 治理团队；**★★★★★**。

### 5. vercel-labs/agent-browser

- **主要用途**：让 AI Agent 通过命令行打开网页、读取可访问性树，并以元素引用执行点击、输入、下载和录制。
- **技术栈**：Rust 原生 CLI、Chrome DevTools Protocol、Node/npm 包装、后台 daemon、MCP/Skills；Apache-2.0。
- **近期增长及口径**：约 **+916 Star/24h、+2,994 Star/7d**。当前 48,715 Star、3,319 Fork，Fork +47，保持第五。
- **贡献与讨论**：近 7 天约 33 次提交、20 个新 Issue；最新改为按平台分发原生二进制并优化大型页面快照。问题涉及 Lightpanda 状态恢复、daemon 卡死和 Chrome 标志失效。
- **爆发原因（推断）**：浏览器操作正在从重型 SDK 转向 Agent 友好的短命令、文本快照和可恢复会话；跨平台二进制降低了部署门槛。
- **亮点**：可访问性树输出紧凑、引用适合模型使用，并提供会话、录制、调试、权限和多浏览器后端。
- **潜在风险**：浏览器会接触 Cookie、密码、下载文件和第三方内容；网页提示注入、域名跳转和危险操作必须由 allowlist、确认策略、隔离 profile 和审计日志约束。
- **适合人群与关注程度**：浏览器 Agent、自动化测试、研究采集和沙箱平台团队；**★★★★★**。
