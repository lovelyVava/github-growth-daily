## 项目分析

### 1. elementalsouls/Claude-BugHunter

- **主要用途**：为 Claude Code 提供漏洞挖掘与外部红队 Skill 包，覆盖 24 类漏洞、企业身份和基础设施攻击矩阵。

- **近期增长及口径**：约 **+1,716 Star/24h**；当前约 18.4k Star、2.0k Fork。较上一期 +1,803 小幅回落 4.8%，但仍断层领先日榜。
- **贡献与讨论**：近七日约 25 次提交、15 个新议题；最新提交加入 Scope 导入，并修复三个 fail-open 路径及分类、JSON 提取和秘密扫描问题。
- **爆发原因（推断）**：大量真实披露模式被包装为 Agent 可调用技能，降低了侦察、验证、报告与平台对接成本。
- **亮点**：安全知识结构化程度高；近期更新直接处理范围门禁而非只扩充提示词。
- **潜在风险**：只能用于明确授权范围；Scope fail-open、误报、敏感信息落盘和攻击性命令误用都可能造成真实伤害。

### 6. GoogleChrome/modern-web-guidance-src

- **主要用途**：把现代 Web 平台能力、最佳实践和兼容性数据变成编码 Agent 可检索、可评测的技能，减少生成陈旧前端模式。
- **技术栈**：TypeScript/Node.js 22+、CLI 安装器、知识指南、Legacy Scanner、评测与覆盖率面板；Apache-2.0。
- **近期增长及口径**：24 小时直接值缺失；约 **+3,575 Star/7d**、相对周增约 53%。当前约 10.3k Star、813 Fork。
- **贡献与讨论**：近七日约 44 次提交、17 个新议题；最新修正 WCAG 非模态对话框措辞，议题涉及 Vue/Svelte/CSS Modules 扫描、隐私示例和 IME 安全提交。
- **爆发原因（推断）**：LLM 训练语料含大量遗留 Web 写法，而浏览器平台已提供更原生、性能更好且无障碍更清晰的替代方案。
- **亮点**：由 Chrome、Edge、Firefox、MDN 团队与社区共同维护，并把规则与评测结合，而不是单纯静态提示词集合。
- **潜在风险**：规则可能领先于企业浏览器基线；自动现代化扫描对框架特有语法存在误报/漏报，不能直接批量改写生产代码。
- **适合人群与关注程度**：前端平台、Web 标准、浏览器兼容、无障碍及编码 Agent 评测团队；**★★★★★**。

### 7. ag-ui-protocol/ag-ui

- **主要用途**：定义 Agent 与用户应用之间的双向事件协议，统一流式文本、工具调用、共享状态、人机中断和子 Agent 事件。

- **近期增长及口径**：24 小时直接值缺失；约 **+3,620 Star/7d**、相对周增约 21%。当前约 21.3k Star、2.2k Fork。
