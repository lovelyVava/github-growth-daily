### 1. cloudflare/security-audit-skill

- **主要用途**：把编码 Agent 组织成多阶段安全审计流程，覆盖侦察、覆盖率驱动挖掘、候选验证、结构化发现与独立复核。

- **近期增长及口径**：约 **+2,716 Star/24h**，相对日增约 **6.8%**；按 10 月 17 日至 24 日站点快照差估算约 **+11,967 Star/7d**。当前 42,611 Star、2,658 Fork，Fork 较上期 +151；连续第一。
- **贡献与讨论**：近 7 天默认分支 0 次提交、作者身份缺失、6 个新 Issue；仍有目标仓库名驱动输出路径与历史运行复用的路径逃逸/跨目标污染问题。
- **爆发原因**：独立验证、覆盖账本和机器可校验 findings 直击 Agent 安全审计的可信度难题；Cloudflare 品牌与可安装 Skill 形态进一步放大传播。
- **亮点**：区分 confirmed、needs_validation、rejected，并把覆盖状态、证据与复核结果做成可机器验证工件。
- **潜在风险**：无 OS 级隔离时不应执行目标代码；输出路径和历史证据绑定仍需验证。近周零提交说明热度没有同步转化为修复活动。
- **适合人群与关注程度**：AppSec、代码审查平台、Agent 安全评测与漏洞研究流程设计者；**★★★★☆**。

### 2. NVIDIA/OpenShell

- **主要用途**：为自主 Agent 提供受策略约束的私有运行时，让 Agent 可访问文件、网络、包与凭据而不获得宿主机的无限权限。
- **技术栈**：Rust、Kubernetes/容器驱动、策略引擎、网络端点控制、凭据代理与审计机制；Apache-2.0。
- **近期增长及口径**：约 **+1,119 Star/24h**，相对日增约 **6.3%**；快照差估算约 **+2,435 Star/7d**。当前 18,964 Star、1,897 Fork；重新上榜第二。
- **贡献与讨论**：近 7 天约 66 次提交、作者身份缺失、86 个新 Issue；最新提交为 Helm 证书 hook 增加 Pod 标签与注解。新问题涉及纯 TCP 端点误走 HTTP 解析器，以及 WSL2/Kubernetes 下 seccomp notification 探测失败。
- **爆发原因**：Agent 权限边界正在从提示词规则转向可执行的系统隔离与网络策略；NVIDIA 品牌、Kubernetes 部署与多 Agent 运行叙事同时带来关注。
- **亮点**：把凭据、文件、网络和执行权限放进同一控制面，适合研究 Agent 沙箱、最小权限与可审计运行时。
- **潜在风险**：项目仍快速迭代；内核、seccomp、Kubernetes、WSL2 和网络协议差异会形成复杂兼容矩阵。策略语义错误可能造成越权或误阻断，部署前需做逃逸与旁路测试。
- **适合人群与关注程度**：Agent 平台、云原生安全、沙箱运行时与企业凭据治理团队；**★★★★★**。
