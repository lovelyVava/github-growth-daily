## 项目分析

### 1. morluto/rea

- **主要用途**：通过统一 MCP/CLI 对网站、JavaScript/Electron 应用、.NET 程序、APK、固件和原生二进制进行证据化逆向分析。
- **技术栈**：TypeScript、Node.js 22+、MCP、Hopper/Ghidra/IDA、JADX、Binwalk/Unblob；MIT。
- **近期增长及口径**：约 **+25,585 Star/24h**，相对日增约 **32.9%**；7 天直接值缺失。当前 103,323 Star、22,661 Fork，Fork 较上期约 +7,566；连续第一。
- **贡献与讨论**：近 7 天提交 **≥100**、24 个作者身份、394 个新 Issue；最新加入对经验证 MIPS16 共享 ELF 镜像的 Ghidra 处理。
- **爆发原因**：项目把网页行为、反编译器、固件和原生二进制工具统一成 Agent 可调用证据链，覆盖面持续扩张；“任何对象都可逆向”的叙事又具有极强传播力。
- **亮点**：静态与动态分析并存，可接入主流反编译器；近期提交与作者数同步增长，说明热度已转化为真实协作，而不只是一次性收藏。
- **潜在风险**：明显双重用途，只能分析获授权目标。外部反编译器、浏览器捕获、安装脚本与 MCP 权限扩大供应链、隐私和主机安全面；394 个新 Issue 表明兼容性与维护压力继续上升。
- **适合人群与关注程度**：获授权的软件审计、兼容性研究、恶意样本隔离分析和企业 `reverse-skill` 团队；**★★★★★**。

### 2. boykopovar/AnyPS5

- **主要用途**：把 PS5 可执行文件重链接为 Windows/Linux 原生格式，并实现系统 PRX 库与着色器重编译，不依赖独立模拟器进程。
- **技术栈**：C++、原生 Relinker、动态链接、SPIR-V、Vulkan、SDL 输入；GPL-2.0。
- **近期增长及口径**：约 **+3,977 Star/24h、+21,365 Star/7d**，相对日增约 **15.3%**。当前 30,042 Star、2,581 Fork，Fork 较上期约 +341；连续第二。

- **爆发原因**：原生重链接路线与传统模拟器差异明显，系统库、线程同步、图形着色器与游戏兼容性持续高频推进。
- **亮点**：公开兼容性和技术债，对不支持状态显式失败；社区 Issue 已形成按游戏、模块和图形路径细分的调试资料库。
- **潜在风险**：系统库与游戏支持仍不完整，用户必须确保二进制来源合法。使用 SPIR-V/Vulkan 不代表 Radeon RX 7900 XTX 已充分验证，仍需逐项核验驱动、扩展与具体游戏路径。

## 最值得深入研究的 3 个项目

### 1. morluto/rea

REA 今天约 +25,585 Star、Fork +7,566、周提交 ≥100，增长、复用与工程活动同时爆发。它与企业 `reverse-skill` 方向高度吻合：应重点拆解“工具调用—证据归档—结论置信度—未知项—人工批准”的闭环，并把网络捕获、JavaScript 应用图谱、Ghidra Bridge 与隔离执行拆成权限清晰的阶段。

### 2. lyogavin/airllm

AirLLM 值得研究的不是“4GB 神奇跑 70B”的标题，而是它如何把模型容量问题重写为分层分片、文件映射、预取和 I/O 调度问题。对 Radeon RX 7900 XTX/ROCm，本地研究应先做兼容矩阵：PyTorch/ROCm、`gfx1100`、Transformers 版本、Attention/量化扩展、磁盘吞吐、首 Token 延迟与每 Token 吞吐分别测量，避免把 NVIDIA 样例直接外推。

### 3. tester-army/e2e

它的周增约 6,564，同时有 ≥100 次提交、15 个作者身份，增长质量优于许多只靠传播的项目。最值得拆解的是“Agent 先探索、确定性断言再验收、成功路径随后无模型回放”的控制回路；这套思路可以迁移到企业前端、移动端、低代码平台和逆向验证场景。落地前应重点评估缓存失效、测试环境身份、遥测和 1.0 前 API 漂移。
