## 项目分析

### 1. mattpocock/skills

- **主要用途**：提供面向真实工程的可组合 Agent Skills，覆盖需求澄清、共享术语、ADR、TDD、故障诊断、代码审查、重构和项目工作流。
- **技术栈**：`SKILL.md`、Markdown、Shell/Node 辅助、Claude Code Plugin 与 skills.sh 分发；MIT License。
- **近期增长**：日榜约 **+2,758 Star**；周榜值缺失；相对日增约 **1.11%**。当前 250,335 Star、21,155 Fork；较上一期 Fork 约 **+189**，排名上升 3 位。
- **贡献与讨论**：近 7 天约 2 次提交、32 个新 Issue；独立贡献者、PR 与 Discussions 增量缺失。社区反馈显著强于代码提交。
- **爆发原因**：将传统工程方法拆成小而可组合的 Agent Skills，精准对应“需求没问清、代码不可测、架构变泥球”等高频痛点，易于传播和按需安装。
- **亮点**：不绑定模型；支持只读订阅式插件与可编辑复制版；覆盖从领域语言到实施、审查和重构的闭环。
- **潜在风险**：多 Skill 叠加可能产生指令冲突与上下文膨胀；自动更新扩大供应链信任范围；当前增长缺少同等强度的新提交支撑。
- **适合人群**：软件工程师、技术负责人、编码 Agent 使用者，以及希望逐步引入 AI 工程规范的团队。
- **值得关注程度**：**★★★★☆**。热度和问题匹配度很高，但应以自有仓库基准验证流程收益。

- **近期增长**：日榜约 **+1,679 Star**；周榜值缺失；相对日增约 **1.35%**。当前 125,942 Star、6,762 Fork；较上一期 Fork 约 **+94**。

- **主要用途**：用 Skill 压缩 Agent 输出风格，并通过本地代理压缩 Agent 读取的日志、JSON、代码、diff 和网页上下文，同时保留可恢复原文。
- **技术栈**：Go 核心代理、Node.js CLI/Hooks、SQLite 原文存储、BM25 上下文打包、Agent Skills 与 MCP；Skill/CLI 多为 MIT，Engine 相关目录为 BSL-1.1。
- **近期增长**：日榜约 **+501 Star**；周榜值缺失；相对日增约 **0.49%**。当前 103,564 Star、6,007 Fork；较上一期 Fork约 **+13**。
- **贡献与讨论**：近 7 天提交 **≥100**、约 27 个新 Issue；独立贡献者、PR 与 Discussions 增量缺失。
- **爆发原因**：Agent 成本焦点从单次模型价格转向输入上下文膨胀；项目把输出约束、输入压缩、恢复机制和成本基准组合成完整叙事。
- **亮点**：区分输出与输入压缩；保留恢复句柄；公开失败案例与额外开销；支持 30 多种 Agent，并提供本地历史用量分析。
- **潜在风险**：宣称的输出节省不等于全会话节省，规则本身也增加输入；压缩可能丢失关键上下文；代理位于 Agent 与模型提供商之间，凭据、日志与更新链需审计；BSL-1.1 限制商业化方式。
- **适合人群**：高频编码 Agent 用户、FinOps、上下文工程、日志密集型开发和本地隐私敏感团队。
- **值得关注程度**：**★★★★☆**。工程活动很强，但正确率和总成本必须用真实任务验证。
