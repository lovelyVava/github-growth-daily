## 统计口径与限制

1. **24 小时新增 Star**：采用 GitHub Trending 日榜的 `stars today`；这是滚动窗口，不等于自然日或相邻快照差。页面顺序不严格按该值排序，本报告按数值重新排序。
2. **7 天新增 Star**：采用周榜的 `stars this week`。只有公开周榜直接展示的数值才写入；未进入周榜的项目标为“缺失”，不从累计 Star 反推。
3. **当前 Star/Fork**：采用 2026-09-11 08:00–08:08 的 GitHub API 快照。Trending 与 API 抓取时间略有不同，因此累计数可能存在小幅时差。
4. **Fork 变化**：仅对连续进入前十的项目比较 9 月 10 日与 9 月 11 日相邻快照；新上榜或重新上榜项目不估算 24 小时 Fork 变化。
5. **工程活跃度**：统计 2026-09-04 00:00 UTC 起约 7 天的默认分支提交，单仓最多读取 100 条；触及上限写作“≥100”。
6. **贡献者活跃度**：按提交记录中的 GitHub 账号或作者邮箱去重估算，可能拆分同一人的多个身份或包含机器人；截断仓库写作下限，不等同累计 Contributors。
7. **讨论热度**：统计同一窗口新建 Issue，排除 PR。若接口首 100 条记录仍全部落在窗口内，则写作下限；Issue 数量不等于有效人工讨论。
8. **开源口径**：`system-design-notes` 没有明确许可证；源码可阅读不等于获得复制、修改、分发或商业使用授权。`gods-eye-view` 的 MIT 仅覆盖代码，第三方数据与模型资产另受各自条款约束。
9. **爆发原因**：根据 README、近期活动与榜单表现作分析推断，不代表维护者官方结论。

## 项目分析

### 1. ayghri/i-have-adhd

- **主要用途**：为编码 Agent 提供行动优先、限制旁支、短列表和明确下一步的输出规则，减少答案被长篇解释掩埋；并不要求用户具有 ADHD 诊断。
- **技术栈**：Python、Markdown Skill、Hooks，以及 Claude Code、Codex、Cursor、OpenCode、Gemini、Kimi、Qwen 等多宿主插件配置；MIT License。
- **近期增长**：日榜约 **+3,882 Star**、周榜约 **+10,215 Star**；相对日增约 **11.3%**。当前 38,227 Star、2,199 Fork；较上期 Fork 约 **+178**，连续第一。
- **贡献与讨论**：近 7 天约 21 次提交、约 6 个作者身份、14 个新 Issue；相较昨日，工程活动明显增强，不再只是单纯传播。
- **爆发原因**：编码 Agent 输出膨胀形成普遍痛点；规则简单、多宿主、复制即用，且“直接告诉我下一步”具有强社交传播性。
- **亮点**：强调行动优先、列表上限、可见进展、具体时间估算和每轮状态重述，能降低工作记忆负担。
- **潜在风险**：过度压缩可能省略前提、证据和安全边界；医疗化命名易让交互偏好被误解为诊断；复杂任务不宜全局套用。
- **适合人群**：容易被长回答淹没的学习者、开发者，以及需要短步骤和明确下一动作的 Agent 团队。
- **值得关注程度**：**★★★★☆**。适合作为可开关的简洁交互层，不应覆盖合规、安全与复杂设计所需的完整解释。

### 2. bilawalsidhu/gods-eye-view

- **主要用途**：在浏览器 3D 地球上统一展示航班、船舶、卫星、地震、火情、交通、公共摄像头和无线电等开放信号，并支持语音控制与场景分析。
- **技术栈**：JavaScript、Vite、Cesium/WebGL、GLSL、公开地理与遥测 API、可选 OpenAI 实时语音 Agent；代码采用 MIT License，数据与 3D 资产另行授权。
- **近期增长**：日榜约 **+1,762 Star**、周榜约 **+6,051 Star**；相对日增约 **7.9%**。当前 24,207 Star、5,036 Fork；重新上榜第二。
- **贡献与讨论**：近 7 天约 5 次提交、约 1 个作者身份、新 Issue **≥46**；讨论量高，但代码贡献集中于单一身份。
- **爆发原因**：逼真的“情报驾驶舱”视觉表现叠加真实公开数据、病毒式演示视频与无需密钥的快速启动，天然适合传播。
- **亮点**：模块化图层、真实与模拟数据明确标注；支持目标跟踪、驾驶舱、视域、轨迹、分享链接与语音白板；可本地运行。
- **潜在风险**：第三方数据授权复杂，TeleGeography 数据为 CC BY-NC-SA，Google/OpenSky 等还受商业与配额条款限制；浏览器侧 Cesium/Google Key 需来源限制；公开摄像头和位置数据存在隐私、误读与双重用途风险。
- **适合人群**：GIS/OSINT 教学、实时可视化、灾害与交通演示，以及需要 3D 地理交互原型的开发者。
- **值得关注程度**：**★★★★☆**。展示和模块化价值强，生产或商业使用前必须逐项审计数据来源、密钥与伦理边界。

### 10. vastsa/PI-Desktop

- **主要用途**：提供本地优先的 AI 编码 Agent 桌面工作区，集中管理项目、会话、模型、命令、审查、预览、Skills、MCP、插件和子 Agent。
- **技术栈**：Electron/TypeScript、Rust Host Core、Pi Agent Harness、SQLite/JSONL、系统密钥链、OpenAI 兼容 API、Ollama/LM Studio；LGPL-3.0。

- **贡献与讨论**：近 7 天提交 **≥100**、作者身份 **≥6**、新 Issue **≥62**；处于高强度 Early Preview 阶段。
- **爆发原因**：用户希望脱离单一 IDE 与云端账户，在本地统一接入自选模型、长会话、权限审批和可安装扩展。
- **亮点**：Agent/Plan/Goal 三种门禁；权限层和 Review 面板；本地 SQLite/JSONL、系统密钥链、无内置遥测；支持本地模型网关和断点恢复。
- **潜在风险**：Early Preview 的 API 和插件接口会变化；插件进程是受权限控制的可信代码而非完整 OS 沙箱；回环 MCP 控制接口具有与桌面相近的操作权限。
- **适合人群**：本地模型用户、需要可视化审查与权限门禁的开发者、多项目长会话和 Agent 桌面研究团队。
- **值得关注程度**：**★★★★★**。相对增速和工程活动同时领先，适合隔离环境试验，暂不宜直接充当企业生产控制面。

## 当天技术趋势

1. **Agent 基础设施从规则层下沉到控制面**：`i-have-adhd`、`superpowers` 仍代表交互与流程规则，`teamai-cli`、`OmniRoute`、`PI-Desktop` 则进一步承接团队分发、模型路由、权限审批、会话与桌面宿主。
2. **高增长项目开始同时具备高工程活动**：`teamai-cli`、`OmniRoute`、`PI-Desktop` 均达到 100 条提交读取上限，说明本期热点不只来自内容传播；但高频迭代也意味着接口漂移与供应链风险更高。
3. **多模态体验继续从生成走向应用闭环**：`OpenMAIC` 把课件、语音、白板、测验和仿真组合成课堂；`gods-eye-view` 把实时地理数据、3D 渲染和语音 Agent 组合成可操作空间界面。
4. **“一个入口接所有模型”需求升温**：`OmniRoute` 用统一端点、自动故障切换和成本/配额感知缓解多供应商碎片化，`PI-Desktop` 则从本地桌面承载模型、Skills 与审查。
5. **可版本化视觉资产仍在扩张**：`diagram-design` 与 `awesome-gpt-image-2` 分别把架构图和提示词案例变成可复用、可审查、可组合的工程资产。
6. **许可证需要细分到代码、数据与资产**：`system-design-notes` 完全缺少许可证；`gods-eye-view` 虽为 MIT 代码，但捆绑数据、3D 模型和在线服务可能限制商业用途，不能只看仓库徽章。

## 最值得深入研究的 3 个项目

### 1. Tencent/teamai-cli

**理由**：相对日增约 28.8%，近 7 天提交达到上限且至少 15 个作者身份参与；它原生支持 GitLab、私有 Git、角色/标签分发、MR 审批和团队经验召回。建议优先验证：规则版本锁定、Hook/MCP 白名单、敏感信息脱敏、MR 审批、回滚以及内网镜像。

### 2. diegosouzapw/OmniRoute

**理由**：首次上榜即具备 ≥100 次提交、≥11 个作者身份，覆盖模型健康、额度、成本、延迟、故障切换和上下文压缩，代表编码 Agent 网关的高集成方向。研究应从最小化 PoC 开始：只接 2–3 个正规 API、独立低权限密钥、禁用 Web 会话桥接与 MITM、开启审计日志，并专门复核近期 JWT 边界问题。

### 3. vastsa/PI-Desktop

**理由**：本期相对日增最高，提交再次达到上限；它把本地模型、系统密钥链、权限门禁、Review 面板、长会话和子 Agent 集中到桌面端。最值得验证的是本地模型延迟、插件进程权限、回环 MCP 令牌、会话数据落盘范围，以及 Early Preview 升级兼容性。
